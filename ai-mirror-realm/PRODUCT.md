# Product: AI 镜界

<!-- impeccable:product-schema 1 -->

## Platform

web

## Product Purpose

AI 镜界是可在本地运行的 AI 写真网站。公开目录让用户先看真实主题样片；持有邀请码的用户可以保存私人面部照片档案，选择主题或自由描述，创建真实生成任务并查看、下载结果。

当前产品和界面依据用户授权，整体采用美图 AI 写真的参照方向。规范以本文件和 [DESIGN.md](DESIGN.md) 为准；本轮范围见 [还原计划](docs/meitu-reconstruction-20261012/PLAN.md)，旧方案记录仅作历史资料。

## Primary User

希望先比较妆造、场景与光线，再用自己的照片制作写真的中文用户。用户可以重复使用私人照片档案，也可以直接上传一张照片开始创作。

## Canonical Flow

`浏览主题 → 邀请码进入 → 选择面部档案或上传照片 → 选择主题或描述画面 → 生成任务 → 查看与保存写真`

新增面部档案是独立的复用路径：`上传 4–9 张同一人的照片 → 命名并保存 → 选择档案制作写真`。档案保存照片引用，不进行模型训练，不承诺训练完成或身份质量评分。

## Routes

| 路径 | 当前用途 |
| --- | --- |
| `/` | 跳转到公开的 `/studio` 目录 |
| `/studio` | 主题写真目录、五类筛选、名称搜索与概念写真入口 |
| `/studio?create=1` | 档案或单张上传、主题、描述与提交任务；私有操作需要邀请码会话 |
| `/access` | 邀请码进入；成功后恢复安全的站内目标路径 |
| `/profiles` | 私人面部档案：新增、查看、重命名、删除与开始创作 |
| `/works` | 真实任务列表、状态筛选、原图与结果、保存、重新制作、删除 |
| `/studio/tasks/[id]` | 等待、失败、完成结果及大图、原图对照、保存与重试 |

旧 `/styles`、`/styles/[id]`、`/create`、`/upload`、`/recharge` 跳转到当前目录；`/profile` 跳转任务列表；`/result?id=…` 跳转对应任务，没有 ID 时进入任务列表；`/login`、`/register` 转入邀请码入口。旧 `variant` 参数不再切换视觉体系。

## Product Rules

- 公开目录包含 153 张真实下载的美图公开样片及对应名称。分类原卡片数为热门 61、求职证件照 42、女性 138、男性 15、儿童 8；分类内重复引用与原顺序保留，跨分类不重复存储图片。搜索按名称覆盖完整目录。
- 样片说明妆造与场景，生成结果来自真实模型任务，预览图不能充当用户结果。本地实现不承诺与美图使用相同模型或产生相同成片。
- 邀请码会话保护上传、档案、任务与私人媒体。邀请码不写入 URL 或浏览器存储，邀请码一次性使用。退出后再次进入需要有效邀请码，跨会话恢复旧账户不属于当前界面能力。
- 新建档案界面要求 4–9 张同一人的照片，每张 JPG、PNG 或 WebP，最大 10MB。逐张显示等待、上传、完成和失败，失败可重试或移除；全部成功后才可保存。档案名为 1–30 个字。
- 档案编辑支持重命名；删除档案保留正在生成的任务与已有写真。任务删除需要确认。
- 快速上传仍支持一张照片。生成必须有照片，并至少选择主题或填写描述；每次创建一条任务，生成一张结果。
- 创作草稿在 `sessionStorage` 按用户 ID 隔离，仅保存描述、主题、筛选与私有文件引用等元数据，不保存人脸图片字节。返回目录、刷新和重新制作恢复描述、主题及完整照片数组；退出清除草稿。
- 描述框限 500 字符。Enter 提交一次，Shift + Enter 换行；输入法确认选字与长按重复 Enter 不提交重复任务。上传、恢复或提交期间阻止重复提交。
- 列表数量与状态来自后端任务，时间以 Asia/Shanghai 显示。新任务保存创建时的档案名称；旧任务缺少快照时按现有档案查找，找不到时显示“本次上传照片”。
- 等待、失败、网络中断和媒体加载失败提供文字与恢复入口；不显示虚构百分比、倒计时、人脸检测或质量评分。
- 本地服务不包含美豆、支付、充值、套餐或订单功能。

## Capabilities and Constraints

- 前端：Next.js 14、React 18、Tailwind CSS、Lucide；后端：FastAPI、SQLAlchemy、SQLite。
- 默认模型为 Seedream 4.5（`doubao-seedream-4-5-251128`）。1–9 张身份照片按数组发送；选主题时将主题样片作为最后一张参考，最多 10 张输入。系统提示词区分身份照片与妆造/场景参考。
- 可选 DeepSeek 只整理用户描述和主题名称，不接收人脸照片、账户信息或私有路径；未配置、超时或异常时沿用原文。用户原始描述保留在最终生图提示词中。
- 服务端校验每张身份照片的当前账户归属。照片与结果通过受保护的媒体接口访问。
- 档案和任务 API 保留旧单图兼容性，允许 1–9 张引用；新建档案界面仍要求 4–9 张。旧主题保留历史任务关联，当前目录不提供旧版原创主题。
- 本轮浏览器验证使用已有 AI 生成样片的四份本地副本，验证多图传输与流程；尚未验证不同真实人脸照片的身份一致性质量。

## Brand Commitments

- 保持自有品牌“AI 镜界”，使用直接中文动作词：新增面部档案、制作写真、保存写真、重新制作。
- 采用用户指定的美图布局和公开素材参照，保留原始来源、名称及 SHA256；不把素材标为原创，不在交付前端中加入竞品公开脚本。
- 美图直接观察范围是公开目录与登录后的 4–9 张上传弹窗。弹窗显示建档消耗 50 美豆、观察账户余额为 0；本轮未付费建档或取得美图结果。竞品状态与本地实测分别记录，详见 [观察边界](docs/meitu-reconstruction-20261012/evidence/README-observation-boundaries-20261012.md)。

## Accessibility

导航、上传、主题选择、档案和任务操作提供可访问名称与清晰焦点。通用浮层限制键盘焦点、支持 Esc，并在关闭后恢复焦点；任务大图使用原生对话框。加载、错误与保存状态提供文字或 live region，减少动态效果偏好下停用动画。移动端保留安全区导航，交付按桌面 1440×900 与手机 390×844 的真实页面核对。

# 写真聊天界面预览

2026-10-06：加入确认后的第三版界面，采用浅桃色图片展示区、白色聊天区与珊瑚红操作按钮。

## 查看

按项目部署文档启动前端后，访问 `/portrait-chat`，或使用首页、桌面导航和手机导航中的“写真聊天预览”入口。Next.js 将该路径临时跳转到 `/portrait-chat/index.html`；所有图片、字体、样式和脚本使用项目内素材，不依赖本地机器路径、独立 Python 服务或外部字体 CDN。生产 standalone 构建会随现有 postbuild 脚本复制这些 public 文件。

## 当前范围

- 左侧显示示例写真，右侧支持提示词输入、快捷建议和连续聊天消息。
- 支持新建对话、对话切换、照片更换、图片放大和示例照片下载。
- 照片上传仅通过 FileReader 保留在当前浏览器内存，不上传到后端。检查 JPG / PNG / WebP、10 MB 大小及实际图片解码。
- 页面和回复明确标注预览；发送消息只记录修改要求，保持已有示例图，**不调用真实生图 API，也不会生成新的写真**。
- 刷新页面会清空预览对话。真实多轮图像编辑和持久化还需后续接入。
- 此入口不展示积分。现有邀请制 `/access`、真实 `/studio` 和作品库继续使用仓库原有流程。

## 文件与素材

界面文件位于 `frontend/public/portrait-chat/`。两张示例照片由 image_gen 生成，分别用于生活写真展示和参考照片演示，不代表真实用户或同一人物身份验证。照片压缩为 WebP；字体为 Noto Sans SC 的本地子集，授权来源在 `assets/Noto-Sans-SC-license-source.txt`；图标来自 Tabler Icons，MIT 授权随 `assets/icons/LICENSE` 保存。

## 验证

原版预览已检查桌面 1487 × 1058、较窄桌面 1024 × 768 和手机 390 × 844，以及上传、无效图片提示、输入、回车发送、对话切换、图片放大和下载。入库版本另行执行前端生产构建与浏览器检查。

# AI 镜界视觉重设计实施单

日期：2026-09-14

## 事实与参考

本次参考 2026-09-14 核验的官方页面：

- Aragon AI：以大幅真实成片、单一高对比 CTA 和“选服装/背景→上传→生成→下载”的短路径建立信任。
- BetterPic：用左侧任务说明、右侧成片对照和缩略图带，让用户先看到结果证据再决定上传。
- Remini：使用黑色沉浸式照片舞台和前后对照，把产品体验做成一次轻量的暗房操作。
- HeadshotPro：用高密度人像墙承载首屏视觉，再用聚焦任务卡承载动作，并把上传、选择、生成状态真实化。

只借鉴信息层级、照片密度、任务卡和状态表达，不复制品牌颜色、Logo、字体、客户素材、评价或未经实现的能力承诺。

## 视觉决定

1. 产品从“白底 SaaS 工具”改成“浅色画廊外壳 + 黑色暗房舞台”。浅色用于门禁和信息，近黑用于照片、工作台和任务状态。
2. 全局强调色改为暗房珊瑚红，保留单一强调色规则；不使用紫色渐变、玻璃拟态或装饰 Glow。
3. 首页首屏改为非对称作品舞台：一句结果承诺、唯一邀请码 CTA、三条事实和高密度本地样片墙；不虚构 Before/After。
4. 邀请页使用“大图 + 任务表单”双栏，移动端隐藏大图，只保留邀请码表单。
5. Studio 保持单页核心路径：上传后立刻看到描述框，主题缩略图作为可选快捷方式；桌面双栏，移动端单一页面滚动，主题横向滑动。
6. Works 和任务页使用深色结果头部，作品图优先，元数据和操作降级；不添加虚假数量、评分或生成时间承诺。

## 实施范围

- `frontend/src/app/globals.css`：更新画廊/暗房色彩 token、阴影和公共背景。
- `frontend/src/components/Navbar.tsx`：提高品牌识别和邀请码 CTA 对比度。
- `frontend/src/app/page.tsx`：作品主导首页、样片带、事实行和更强的公开 CTA。
- `frontend/src/app/access/page.tsx`：邀请任务卡和沉浸式样片布局，保留邀请码-only 行为。
- `frontend/src/app/studio/page.tsx`：强化暗房舞台、输入区域和移动端主题带，不改变接口逻辑。
- `frontend/src/app/works/page.tsx`、`frontend/src/app/studio/tasks/[id]/page.tsx`：结果优先头部与更清晰的状态视觉。
- `DESIGN.md`：记录新的视觉合同和竞品映射。

## 验收

- 工程：`npm run lint`、`npm run build`、后端 pytest 全量通过。
- 交互：邀请码页无登录分支；描述-only、主题-only、组合输入均可用；生成前无方向时 CTA 禁用。
- 视觉：1440×900 与 390×844 实际检查；无横向溢出；固定 CTA 不遮挡输入；loading、error、empty、disabled、focus 状态保留。
- Finish gate：完成一次 Critique → Polish → 复查；不触发真实模型生成或积分/订单流程。

# AI 镜界 Aragon 单图工具式重构规格

## 竞品骨架

唯一主骨架采用 Aragon AI Stylist / Editorial Generator：上传一张照片 → 选择一个 aesthetic/theme → 生成 → 下载。BetterPic 的多图训练、套餐和 AI 评分不进入产品；只保留可真实验证的上传指导。Remini 的 model image 机制映射为本地主题缩略图。

## 删除范围

- 删除公共 `/styles` 目录、搜索、分类和 `/styles/[id]` 详情交互。
- 删除 `/create?style=`、`/result?id=` 与 `/profile` 的旧页面逻辑。
- 删除首页长营销结构、FAQ、模板目录和摄影画册视觉。
- 删除结果页分享链接、技术错误、突出任务编号和任务事实卡。
- 旧地址只保留重定向兼容层。

## 新主流程

1. `/`：主按钮进入 `/access?mode=invite`，登录入口进入 `/access?mode=login`。
2. `/access`：统一邀请注册和登录；成功进入 `/studio`，会话过期时安全返回原路由。
3. `/studio`：上传自拍成功后展开主题选择；选中主题后直接生成。
4. `/studio/tasks/[id]`：显示真实等待、失败或完成；失败不泄露内部错误。
5. `/works`：查看结果与任务，进入统一任务路由。

## 后端合同

复用现有认证、邀请、风格、上传、生成、任务、媒体和删除接口。不新增支付合同。HTTPX 运行时增加 SOCKS 支持；任务接口对用户输出稳定通用错误，详细异常只记录服务端日志。

## 验收

- 旧页面均已成为重定向，不再渲染旧 UI。
- 邀请注册 → Studio → 上传 → 选主题 → 创建任务可完成。
- 任务状态刷新、失败恢复、完成下载和作品库可完成。
- 生成失败不出现代理、包名、上游响应或堆栈信息。
- 前端 lint/build、后端测试/compileall 通过。
- 真实浏览器验证 1440×900 与 390×844，并通过 Agency UI Finish Gate。

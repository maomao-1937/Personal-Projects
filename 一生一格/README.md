# 一生一格：拖延症救命稻草

面向手机使用的人生周历。每格代表从生日开始的连续 7 天；用户可自行设置出生日期和展示终点（年龄或具体日期），为每周留下记录。展示终点由用户选择，不是寿命预测。

## 本地运行

需要 Node.js 24 或更新版本。第一次运行：

```bash
npm ci
```

复制 `.env.example` 为 `.env`，填写数据库路径、访问地址和至少 32 字符的随机 `AUTH_SECRET`。管理员创建账号并生成该用户专属的邀请码：

```bash
npm run invite -- create
```

把命令输出的邀请码通过可信渠道交给对应用户。用户每次在新设备登录时输入这枚邀请码；在同一设备上会话有效期间无需重复输入。分别启动两个终端：

```bash
npm run dev:api
npm run dev
```

打开 `http://127.0.0.1:5173/`。本机服务仅监听本机地址。运行 `npm test` 测试日期与账号接口，运行 `npm run build` 生成前端资源。只查看界面时，可以打开 `http://127.0.0.1:5173/?preview=1`；预览不会登录个人账号。

邀请码仅在生成时显示一次。遗失或泄露时，管理员可以运行 `npm run invite -- rotate <账号ID>` 轮换邀请码；旧码和旧会话失效，账号资料保留。仓库不包含实际邀请码、密钥、数据库或备份，首次运行需要自行创建账号。

## 当前产品

- 每人一枚专属邀请码，凭码直接登录。每个账号独立保存日期、周记录、今日角色、个性化提醒和音效偏好。退出后隐藏该账号内容。
- 目标与行动：面试生成可修改的准备阶段，跑步按自选时长与每天/隔天频率安排，自定义事情提供三步本地建议。支持完成、撤销、按原因反馈、调整目标日期和逐项修改行动；所有记录随账号保存，未设置生日也可开始目标。
- 当前建议在本机按规则生成，不连接AI服务，不产生模型接口费用。最多20个目标、每目标60项行动；长期跑步安排最多先生成60次。计划时间只保存安排，当前没有关闭网页后的系统通知。
- 三位原创角色：理性决策者、猴子、恐惧怪兽。点角色可看简介及短音效；猴子掌舵时出现简短提醒。角色音效可关闭。
- 手机首页依次显示本周、目标、角色和完整周历。三个立体角色支持点击查看简介，当前选中角色显示白色亮边。时间设置使用分段日期输入、年龄滑杆和快捷选项。
- 修改后自动同步并显示状态；服务暂时不可用时，本机保留待同步草稿，可重试。两台设备同时修改时，用户选择保留本机或云端版本。
- 首次登录若发现旧版本机档案，会先展示两份资料的日期与记录数量，由用户决定是否导入。改动有记录的出生日期前会提示旧记录保留方式。
- 支持导出 SVG 周历。生产构建包含 PWA 安装资源；手机浏览器可将 HTTPS 页面添加到主屏幕。

**计算口径：**一格为连续 7 天，从生日当天开始。按真实日期计算，年龄行可能有 52 或 53 格；末格若不到 7 天，会标注范围内天数。2 月 29 日出生者在平年按 2 月 28 日计算周年。

## 数据边界

账号资料存入服务端 SQLite 数据库，登录会话使用 HttpOnly Cookie。服务端不保存邀请码明文；管理员须通过可信渠道逐人发放。邀请码相当于该用户的登录凭证，拿到它的人可以进入该账号；发现泄露时管理员可轮换邀请码，旧码和旧会话随即失效，原有周历保留。本机还会保存该账号的同步草稿；退出后页面不显示它，重新登录同一账号可恢复。角色音效开关随账号档案同步。旧版尚未同步的本机草稿只会在确认属于该账号后提示用户选择，且不会自动覆盖云端。已缓存的静态资源可离线打开，但冷启动时仍需连接服务端检查会话，因此不能保证离线打开个人资料。当前冲突处理以整份档案为单位，不会自动合并两个设备的修改。用户量预期在 10 人以内。

当前版本不包含背景音乐。

本项目使用 React、TypeScript、Vite 和 Node.js，并参考 [Agency Agents](https://github.com/msitarzewski/agency-agents) 的角色分工思路。

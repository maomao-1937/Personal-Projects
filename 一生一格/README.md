# 一生一格：拖延症救命稻草

一款面向手机使用的人生周历。每个格子代表从出生日期开始连续的 7 天；用户可以选择展示到某个年龄或具体日期，并为每周留下记录。展示终点仅用于自定义视图，不是寿命预测。

**在线体验：**[一生一格](https://life.150-5-131-41.sslip.io/)（私人周历需要专属邀请码）

## 功能

- 通过专属邀请码登录；每个账号独立保存日期、周记录、今日角色和提醒设置。
- 理性决策者、猴子和恐惧怪兽三位角色提供简介与可关闭的短音效；猴子掌舵时出现个性化提醒。
- 手机端优先展示本周，支持调整出生日期、展示终点和浏览全部周格。
- 自动同步记录；网络暂时不可用时保留待同步草稿，并处理跨设备修改冲突。
- 支持导出 SVG 周历，以及将 HTTPS 页面添加到手机主屏幕。
- 当前版本不包含背景音乐。

## 本地运行

需要 Node.js 24 或更新版本。

```bash
npm ci
cp .env.example .env
```

在 `.env` 中设置数据库路径、访问地址和至少 32 字符的随机 `AUTH_SECRET`。然后创建账号：

```bash
npm run invite -- create
```

命令只在创建时输出一次邀请码。分别启动 API 和前端开发服务：

```bash
npm run dev:api
npm run dev
```

打开 `http://127.0.0.1:5173/`。运行 `npm test` 和 `npm run build` 可检查测试与生产构建。

## 数据与安全

账号资料存储在服务端 SQLite，登录会话使用 HttpOnly Cookie；服务端只保存邀请码的摘要。邀请码相当于账号登录凭证，持有码的人可以访问该账号。请勿将邀请码、`.env`、数据库、备份或私人音频提交到公开仓库。遗失或泄露时，管理员可以运行 `npm run invite -- rotate <账号ID>` 轮换邀请码。

本项目使用 React、TypeScript、Vite 和 Node.js。产品创作参考了 [Agency Agents](https://github.com/msitarzewski/agency-agents) 的角色分工思路。

| 比较点 | 概念图特征 | 实现结果 | 结论 / 已知偏差 |
|---|---|---|---|
| 整体布局 | 顶部项目条、六步进度、深色音频带、Scene/Cut/Inspector 三栏、底部状态条 | 1440 宽度下保持相同五层结构，三栏宽度约为 280 / 弹性中区 / 350 px | 高度和层级基本一致；为让 900 px 视口内 Inspector 动作完整可见，表单纵向间距比概念图稍紧凑。 |
| 色彩与材质 | 石墨黑媒体区、暖灰工作面、紫蓝主操作、独立状态色 | 通过 CSS Token 实现 `#11131A` / `#181B24` / `#F4F1EA` 及紫蓝品牌色，成功/运行/失败/等待均有图标和文本 | 忠实于已批准的混合明暗方向；未引入玻璃拟态或霁虹外发光。 |
| 波形与 Beat | 密集波形、Beat 竖线、Cut 时间选区、BPM 124 | 确定性 CSS 柱体、七个 Beat Marker 和紫色选区，无随机数与 Hydration 差异 | 信息含义一致；概念图波形更细密，实现用更规整的抽象柱代替。 |
| Cut 状态 | Cut 04 完成、05 运行 62%、06 失败、07 排队 | 四张卡片与概念图顺序和状态一致，状态不仅依赖颜色；Cut 06 单独重试不改变 Cut 04 | 交互和语义忠实；无版权风险的 CSS 色块代替真实视频帧，因此影像细节低于概念图。 |
| Inspector | 选中 Cut 06 后显示目的、提示词、景别、运动、时间、失败原因和动作 | 字段、错误、保存与重新生成均可见；保存后明确提示“未发送到服务端” | 功能层级一致；为实现 44 px 操作目标与单屏展示，部分字段布局比概念图更紧凑。 |
| 底部 Preview 条 | 已完成/生成中/失败/排队汇总，Preview 过期和主动作 | 桌面端固定在视口底部，平板和手机改为文档流；修改提示词后切换为“预览需要更新” | 桌面忠实，移动端的非固定化是为避免遮挡焦点和内容的有意降级。 |
| 响应式 | 390 单列，768 收窄 Scene + 可展开 Inspector，1280/1440 三栏 | Playwright 在 390×844、768×1024、1280×800、1440×900 验证无水平溢出；768 的 Inspector 为可展开右侧抽屉 | 符合断点意图；390 优先显示 Scene 与 Cut，Inspector 通过页内折叠控件展开。 |
| 排版与图标 | 中文系统字体、紧凑信息密度、线性图标 | 使用系统中文字体栈、等宽时码和单一 Lucide 图标族 | 视觉语言一致；品牌标识为代码生成的拍板符号，不复制概念图中的具体音符造型。 |

# AI 对话质检器前端 MVP 实现计划

**目标：** 构建可部署、可访问、可真实联调的单页工作台，覆盖邀请码访问、销售／客服场景、对话输入、分析状态、三种报告状态、证据轨道、复制和匿名反馈。

**架构：** Next.js App Router 提供页面与同源后端 Route Handler 代理；Zod 守住 API 边界；React 局部状态承载一次性报告。设计系统通过 CSS 语义变量与轻量自建组件实现。

## 任务 1：工程骨架与 API 契约

- 先写 API schema 与客户端失败测试。
- 创建 Next.js、Tailwind、Vitest、Playwright、ESLint 与严格 TypeScript 配置。
- 实现运行时可配置的同源代理、统一 `ApiError`、访问／分析／反馈请求和运行时校验。
- 验证：API 单元测试、typecheck、lint。

## 任务 2：访问入口与应用壳

- 先写“检查访问、邀请码兑换、错误修正”组件测试。
- 实现受邀访问页；文案不使用注册、登录、账号或密码。
- 实现原创品牌标记、键盘焦点、跳至主要内容和移动端布局。
- 验证：RTL 交互测试和代表页截图。

## 任务 3：对话输入与分析状态

- 先写场景切换、字符限制、防重复提交和错误恢复测试。
- 实现销售／客服切换、格式示例、字符计数、清空、请求中禁用和真实错误提示。
- 请求使用 `crypto.randomUUID()` 生成幂等键；同一点击只发一次。

## 任务 4：报告与证据轨道

- 先写 `scored`、`partial`、`unable_to_score` 三种渲染测试。
- 实现总分／覆盖度、风险、主要问题、建议回复、六维详情、限制和复制。
- `partial` 与 `unable_to_score` 不渲染总分；证据显示 `tN` 节点和逐字 quote。

## 任务 5：匿名反馈与完整状态

- 先写有用／无用、原因更新、反馈失败测试。
- 实现反馈控件、退出访问、空状态、失败状态、剩余额度和过期访问恢复。
- 错误使用后端安全 message；不得显示堆栈或原始未知数据。

## 任务 6：自动化与浏览器核验

- Vitest + RTL 覆盖核心组件和 API 边界。
- Playwright 使用可控 API fixture 跑邀请码 → 分析 → 报告 → 反馈闭环。
- 启动真实后端无 Key 与真实前端，验证访问、同源 Cookie、503 错误和额度不扣。
- 在桌面与移动视口截图，自检视觉、溢出、键盘焦点、对比度与 reduced motion。
- 最终门禁：lint、typecheck、unit、Playwright、生产 build 全部退出码 0。

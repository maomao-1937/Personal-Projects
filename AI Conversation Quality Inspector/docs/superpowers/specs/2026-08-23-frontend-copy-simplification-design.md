# 前端文案精简设计

## 目标

精简邀请码页和质检工作台中的说明性文案，让首屏更紧凑，并降低与核心操作无关的信息噪声。邀请码校验、额度判断和分析流程保持不变。

## 已确认方案

采用直接删除 DOM 的方式，不使用 CSS 隐藏，也不添加替代文案。

### 邀请码页

- 将主标题固定为单行「把判断，钉回原话。」。
- 缩小主标题字号；桌面端和移动端均使用响应式字号，并通过不换行规则保持单行。
- 删除六维质检说明文案。
- 删除邀请码次数说明文案。
- 删除「原始聊天和完整报告不会保存到服务端」及其图标。
- 删除文案后收紧标题、证据示例和邀请码表单之间的垂直间距。

### 质检工作台

- 删除右上角「剩余额度 50 / 50」展示。
- 保留额度数据和额度耗尽判断；额度为 0 时仍禁用分析按钮并显示「额度已用完」。
- 删除「对话输入」标题右侧的「不保存原文」标签及其图标。
- 保留退出访问、场景选择、聊天输入、字数限制和分析功能。

## 组件与样式范围

- `AccessGate`：删除 3 段说明内容，移除不再使用的属性和图标导入，合并标题文本。
- `Workbench`：删除额度展示和隐私标签，移除不再使用的图标导入。
- `globals.css`：调整标题响应式字号和不换行规则，删除只服务于被移除元素的样式。

## 验收标准

- 页面中不再出现用户指定删除的 5 段文案或额度展示。
- 主标题在 390 px 和 1440 px 宽度下均为单行，且不发生横向溢出。
- 邀请码兑换、退出访问、额度耗尽保护和分析提交行为不变。
- 组件测试、类型检查、Lint 和生产构建通过。

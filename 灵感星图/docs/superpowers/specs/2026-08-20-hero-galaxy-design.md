# 首页银核银河视觉设计

## 目标

将首页右侧现有黑洞视觉替换为「银核星盘」银河。新视觉需要与当前深紫宇宙主题一致，并通过中心银河与外围双翼光弧的独立运动，形成“看似一体、实则分层”的空间感。

## 视觉结构

组件沿用首页右侧绝对定位的装饰区域，不影响标题、正文和操作按钮。

- 银河核心：使用深黑星核、白色高光、银紫星盘和细密星尘组成。中心保持高反差，边缘逐渐融入页面背景。
- 银河旋臂：围绕星核形成扁平、锐利的椭圆星盘，颜色以银白、淡紫和蓝紫为主，避免大面积高饱和霓虹。
- 双翼光弧：使用两个独立视觉层构成上下错位的银紫光弧。光弧的颜色、倾角和中心银河一致，但不与银河共享动画。
- 环境辉光：保留低透明度的外围紫色光晕，让银河自然嵌入星空背景，不增加新的文字或交互。

## 动效

- 银河核心缓慢匀速旋转，保持稳定、克制的观测感。
- 双翼光弧独立匀速旋转，周期为 48 秒，是现有 24 秒动画速度的一半。
- 双翼与银河核心设置轻微角度错相，使二者看似属于同一星系，但运动并不完全同步。
- 动画仅使用 CSS transform 和 opacity，避免布局抖动。
- 当系统启用 `prefers-reduced-motion: reduce` 时，停止所有银河旋转动画。

## 响应式表现

- 桌面端保持当前约 500 像素的视觉占位，不遮挡左侧标题和按钮。
- 平板端沿用现有右侧溢出策略，同时降低整体不透明度。
- 手机端缩小并向右上偏移，进一步降低亮度，确保标题仍是视觉第一层级。

## 实现边界

- 仅修改首页银河装饰所需的 HTML 与 CSS。
- 不引入图片、Canvas、WebGL 或第三方动画依赖。
- 不改变首页文案、布局、登录、素材管理或 AI 功能。
- 保留 `aria-hidden="true"`，银河继续作为纯装饰元素。

## 验收标准

1. 首页右侧不再呈现纯黑大球，而是可辨识的银紫银河盘。
2. 银河中心与双翼光弧在视觉上属于同一套色彩和空间结构。
3. 双翼光弧独立旋转，完成一圈需要 48 秒。
4. 桌面、平板和手机宽度下，银河不遮挡主要内容。
5. 减少动态效果模式下动画停止。
6. 页面现有交互与自动化测试保持正常。

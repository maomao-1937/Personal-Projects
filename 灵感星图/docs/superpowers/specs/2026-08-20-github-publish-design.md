# “灵感星图”改名与 GitHub 发布设计

## 目标

将当前私人项目孵化应用统一命名为“灵感星图”，并作为独立子项目上传到
`maomao-1937/Personal-Projects`，最终合并到默认分支 `main`。

## 命名范围

- 浏览器标题、页脚和 README 主标题统一使用“灵感星图”。
- FastAPI 应用名称和 Python 包说明同步改名。
- 不改变现有 API 路径、数据库结构、线上域名和功能行为。
- GitHub 仓库内的项目目录使用 `灵感星图/`。

## 上传范围

上传运行代码、测试、部署配置、依赖锁文件和项目文档。排除以下本地或敏感内容：

- `.venv/`、Python 缓存、测试缓存和编辑器临时文件。
- `incubator.db` 等本地数据库。
- `.env`、API Key、访问令牌和本地 veFaaS 绑定配置。
- 头脑风暴临时页面与截图。

## Git 工作流

1. 从目标仓库最新 `main` 创建 `feat/inspiration-constellation`。
2. 将清理后的项目放入 `灵感星图/`，不修改现有三个项目目录。
3. 运行项目测试、格式检查、JavaScript 语法检查和敏感信息扫描。
4. 只暂存 `灵感星图/`，使用一条约定式提交。
5. 推送功能分支，创建非草稿 Pull Request。
6. 检查 PR 文件范围和可用检查后合并到 `main`，删除远程功能分支。

## 验收标准

- `main` 顶层新增且仅新增 `灵感星图/` 项目目录。
- 项目界面与文档不再展示“私人项目孵化箱”或英文旧产品名。
- 仓库中不存在 `.env`、真实密钥、访问令牌、本地数据库和虚拟环境。
- 测试与静态检查通过，PR 已合并，目标仓库默认分支可读取新项目。

   learn-claude-code 使用说明（Mac）
════════════════════════════════════════

【第一次使用前，只需做一次】
1. 确认电脑装了 Python 3.9 以上版本
   打开「终端」，输入下面命令回车：

       python3 --version

   → 显示 3.9 / 3.10 / 3.11... 就 OK
   → 没显示或版本太低，去 https://www.python.org/downloads/ 下载安装

【每次使用（二选一，推荐方式 A）】

方式 A（最省事）：
   1. 打开「终端」
   2. 把本文件夹里的 run.py 文件直接拖进终端窗口，回车

方式 B：
   1. 打开「终端」
   2. 输入 cd 和一个空格，然后把本文件夹拖进终端窗口，回车
   3. 输入 python3 run.py 回车

启动后：
   → 首次会提示粘贴 DeepSeek API Key（自动记住，以后不用再输）
   → 之后输入 s01 ~ s17 中任意一个，回车，开始上课

【切换课程 & 退出】
   · 在课程里（提示符如 s01 >>）输入 q：退出本节课，回到菜单
   · 在菜单里（提示符 run >>）输入 s02 等编号：切换下一课
   · 在菜单里输入 q：退出整个程序

【常见问题】
Q: API Key 填错了怎么办？
A: 运行课程时如果看到 401 / authentication 报错，就是 key 填错了。
   在 run.py 菜单里输入 key 回车，重新粘贴即可；
   或终端直接运行：python3 run.py setkey

Q: 双击「启动.command」没反应？
A: 压缩包会丢失权限，直接按上面「终端」方式运行即可，效果一样。

Q: 提示依赖安装失败？
A: 打开终端，cd 到本文件夹，手动执行：
       python3 -m venv .venv
       .venv/bin/python -m pip install -r requirements.txt
   再重新 python3 run.py

# 贡献指南

这是一个 **Agent 产品架构蓝图与推导引擎** —— 见 `BLUEPRINT.md`。`s01`–`s17` 是组件参考实现，每个组件用一个可运行的 `code.py` 演示一个 harness 机制。欢迎一切让蓝图与参考实现更有助于构建生产级 Agent 产品的贡献。

## 提 PR 之前

1. 对应一个具体 issue。说清问题是什么、为什么你的改法是对的。一个 PR 只解决一个问题。
2. 参考实现保持聚焦。一个组件参考应清晰演示它的机制 —— 不要加入无关机制、投机性抽象或测试框架，除非该组件本身就在讲这些。若你认为某参考实现需要生产级加固，先在 issue 里论证：目标是让机制清晰，不是复制一份 s15。
3. 蓝图改动必须保持一致。`BLUEPRINT.md` 是唯一蓝图，改动的每一个机制说明都要与对应的 `sNN/README.md` 和 `code.py` 对齐。
4. 改现行文件（`sNN_topic/`、`BLUEPRINT.md`、`scaffold/`、`skills/`），不要改已废弃的目录。
5. 声明 AI 协助。用 agent 没问题，但请说明，并确保你读过、也认可这份改动。

## 哪些会被直接关闭（不做详细评审）

1. 在大量互不相关的仓库里一次性批量提交、由 agent 生成的 PR。作者自己都没参与的代码，我们无法负责任地评审。
2. 让某组件范围超出蓝图设计的改动，或脱离上下文把刻意的简化当成 bug 来"修"的 PR。
3. 没有对应 issue 的 PR。

真正用这份材料构建过产品的贡献，聚焦且讲清理由的，我们始终欢迎。

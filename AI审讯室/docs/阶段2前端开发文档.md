# 第 2 阶段前端开发文档｜可试玩 Web 闭环

## 1. 本阶段目标

用户无需注册即可从落地页生成一宗专属案件，完成审讯、主动结案、查看确定性复盘，并继续生成下一案。

## 2. 范围

### 本阶段包含

- 页面：落地页、案件简报、审讯工作台、三步报告、结果页。
- 组件：按钮、状态标签、证据卡、消息记录、移动抽屉、报告步骤、确认弹窗、评分分项。
- 接口：案件生成/回退/读取、Session 创建/恢复、Turn、Report。
- 状态：初始、加载、提交、思考、成功、失败、报告锁定、强制结案、恢复。
- 产物：结果报告与可复制的无剧透分享文案。

### 本阶段不包含

- 账号、支付、多人、语音、地图、分享图片和云部署。

## 3. 用户流程

1. 落地页点击「开始免费案件」，经历生成骨架、校验证据链和封存真相三个等待状态，再创建匿名 Session。
2. 阅读简报后进入审讯工作台。
3. 选择策略和可选证据，输入 1–200 字问题并发送。
4. 观察证据作用、心理状态、回答与自动笔记。
5. 满足条件后进入三步报告并确认提交。
6. 查看分数、玩家结论、真实结论、时间线、命中和遗漏，选择重审同案、生成下一案或复制分享文案。

## 4. 页面状态矩阵

| 页面/模块 | 初始 | 加载 | 空 | 运行 | 成功 | 失败 | 恢复 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 落地页 | CTA 可用 | 生成中禁用并分阶段告知 | 不适用 | 不适用 | 跳简报 | 可重试或显式使用固定案 | 不适用 |
| 简报 | 显示骨架 | 案件读取 | 案件缺失 | 不适用 | 进入审讯 | 安全错误 | 通过 Session ID |

## 5. 接口契约

- 基础路径：浏览器只请求同源 `/api/v1`；Next.js rewrite 到 `BACKEND_URL`。
- 当前无流式通信；普通请求 10 秒、回合请求 45 秒、案件生成 120 秒超时，请求失败统一进入可恢复错误状态。
- 每次回合提交生成 `requestId`；同一问题的重试复用该 ID，后端返回第一次结果，避免超时后重复扣除回合。
- 网络失败统一转换为可恢复的 `AppError`，保留用户输入。
- Mock 与真实接口：不设运行时 Mock 开关；自动测试通过受控测试替身，真实应用始终调用 FastAPI。

## 6. 实现方案

- 路由：落地页保持 `/`，案件流程使用 `/case/[caseId]/briefing|interrogate|report|result`；旧 `/case/001/*` 路由继续兼容。
- 组件结构：基础 UI 与游戏业务组件分离；页面只编排。
- 状态来源：后端 Session 是事实来源；本地只保留输入、抽屉、报告草稿和 Session ID。
- 响应式：桌面双栏；小于 768 px 进入对话主视图 + 底部抽屉。
- 安全：没有 Key、危险 HTML 或秘密提示词进入浏览器。
- 部署：`output: "standalone"`，未来由构建时 `BACKEND_URL` 固化代理地址。

## 7. 验收标准

- 完成 `落地 → 简报 → 证据 → 提问 → 有效命中 → 状态变化 → 报告 → 评分 → 复盘`。
- 验证无关证据、重复问题、第 3 回合前锁定、第 8 回合强制结案、失败结果完整真相。
- 检查 1440×900、1366×768、390×844、360×800。
- 运行 `npm run lint`、`npm run typecheck`、`npm run test`、`npm run build` 和 Python Playwright 核心闭环。

## 8. 风险与回退

- 后端不可达：页面保留输入并显示重试，不回退到假结果。
- 案件模型不可用或校验失败：显示真实错误和「改用精修固定案」，不静默伪装成 AI 新案。
- 浏览器存储不可用：Session 查询参数仍可恢复。
- 剪贴板权限失败：保留可选择的分享文本。
- 动画不适：系统减少动态设置关闭非必要动画。

## 9. 交付结果

- 修改文件、检查结果、未完成项和已知问题在最终交付时据实补充。

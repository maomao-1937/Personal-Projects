# AI 审讯室案件启动仪式 V2 设计规格

## 目标

把首页从“线稿演示动画”升级为一个克制、写实、可重复验证的 4 秒案件启动仪式。用户点击“生成案件”后，视觉演播和后端生成同时启动；动画只负责建立情绪，业务状态机负责保证请求快慢都不会打断或重复演播。

## 视觉方向

- 场景是一间近乎全黑的审讯空间，站立审讯者位于近景、背对镜头；AI 嫌疑人位于纵深中心，坐在金属凳上。两人和后方冷光大致共线，形成遮挡与压迫感。
- 人物不再由几何 SVG 拼成，改为带透明通道的克制半写实动画电影资产。用户提供的三张图片只参考暗部遮蔽、顶灯关系和压迫感，不复制其人物长相、左右分栏、界面文字或具体构图。
- 审讯者只出现背影或三分之二背影，穿宽松无性别版型的深色外套；嫌疑人采用约 30°–45° 侧脸、低头姿势，眼睛、鼻梁和嘴部不清晰，面部至少 70% 隐入阴影、栏杆遮挡或扫描噪点。发型、肩宽、胸腰和服装均不得形成一眼可辨的男性或女性特征。
- 人物资产本身不做肢体、面部或视差动画。演播阶段只允许嫌疑人图片在 3.65–4.00 秒由透明度 `0` 渐进至 `0.85`；AI 属性继续由独立的低亮度扫描断层、像素错位和数据残影表达，不使用机械脸、发光眼或清晰正脸。
- 空间、光线和金属牢笼继续保持写实材质，使“动画人物 + 真实机械环境”成为产品自己的视觉语言，而不是影视剧截图或游戏 CG。
- 牢笼仍由 DOM/CSS 构建，以便独立下落、回弹和变色。材质使用多层金属渐变、细边高光、接触阴影和景深模糊。
- 色彩严格收敛为黑色空间、冷灰白后光 `#C5CBD3`、3000K 暖白核心 `#FFE8D6`、封存警戒黄 `#D9A74A`。黄色仅用于锁扣和真相强调，不铺满画面。
- 首页只保留一句产品说明和一个主按钮；标题局部使用缓慢流动的低饱和艺术字，“真相”相关文字保持固定警戒黄。

## 生命周期状态机

状态为 `IDLE → CEREMONY → GENERATING? → LOCKING → COMPLETED`，错误进入 `ERROR`：

- `IDLE`：展示人物、后方冷光、单句说明和主按钮。
- `CEREMONY`：点击后立即发起案件请求，并启动不可重复触发的 4 秒 GSAP Timeline。
- 请求早于 4 秒完成：保留结果，动画结束后直接进入 `LOCKING`。
- 请求晚于 4 秒完成：动画结束进入 `GENERATING`，保持牢笼、顶灯和人物微动，直到结果到达。
- `LOCKING`：锁扣转为 `#D9A74A`，人物噪点停止，显示“TRUTH LOCKED / 真相已封存”500ms。
- `COMPLETED`：调用完成回调，存储会话并跳转案件简报。
- `ERROR`：最早在 4 秒演播结束后显示失败信息，可进入现有精修固定案流程；任何错误都不破坏已完成的视觉状态。

同一次运行使用同步 ref 作为互斥锁，保证快速双击只产生一个网络请求和一条时间线。组件卸载时清理所有计时器和 GSAP 上下文。

## 4 秒时间线

| 时间 | 画面与动作 |
| --- | --- |
| 0–250ms | 按钮完成按压反馈；文案和按钮在 220ms 内淡出并轻微失焦。 |
| 250–1250ms | 后方冷光以三次不规则脉冲闪烁，第三次后彻底熄灭。 |
| 1250–1550ms | 舞台降至纯黑，保留 300ms 呼吸停顿。 |
| 1550–2750ms | 机械牢笼从视口上方加速落下，曲线 `power3.in`。 |
| 2750–3150ms | 笼体发生 3px、2px、1px 的快速机械回弹；锁舌卡入。 |
| 3150–3650ms | 顶部 3000K 聚光灯由暗到亮，光锥和地面光池分层扩散。 |
| 3650–4000ms | AI 嫌疑人静态图片仅通过透明度从 0 显现至 0.85，数字扫描层同步建立，不添加人物动作。 |

所有节点使用 GSAP Timeline 绝对时间位置，React 不负责逐帧动画。React 只在第 4 秒切换业务状态，防止渲染时机与动画时间轴互相耦合。

## 生成态与反馈

- `GENERATING` 中顶灯、笼体和人物构图保持稳定，只允许非常缓慢的数字噪点呼吸、空气粉尘漂移和扫描线位移。
- 底部只显示一行状态，按较长间隔轮换“正在检索档案...”“构建行为模型...”“核验证据链...”“封存案件真相...”。
- `LOCKING` 中循环动画立即暂停；锁扣边缘高光过渡为警戒黄；中央封存文案通过短促的透明度与字距收束进入。
- `prefers-reduced-motion` 下不播放闪烁和落笼位移动画，但仍遵守 4 秒业务门槛，直接呈现安全的封存构图。

## 响应式与可访问性

- 桌面端使用前景审讯者、纵深嫌疑人的斜向层次；移动端审讯者裁切到左侧肩背，嫌疑人和牢笼保持中心焦点，文案固定于安全区底部。
- 主按钮可键盘触发，运行中禁用；外层区域使用 `aria-busy`，生成和错误反馈使用 `role=status/alert`。
- 视觉装饰全部 `aria-hidden`；页面保留可读的产品说明，不依赖动画表达产品功能。

## 验收标准

- 点击同一帧发起 `fetchCaseData()`，不等待文案退场。
- 无论接口早晚，`LOCKING` 都不会早于 4000ms；请求超时则稳定停留在 `GENERATING`。
- `LOCKING` 恰好停留约 500ms 后触发完成回调；重复点击不会重放。
- 五档视口无横向滚动，人物不遮挡主按钮，牢笼始终包围嫌疑人。
- 代码中可直接读出 0、0.25、1.25、1.55、2.75、3.15、3.65、4.0 秒时间节点和关键物理曲线。

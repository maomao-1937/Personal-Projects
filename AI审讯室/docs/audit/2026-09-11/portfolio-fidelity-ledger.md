# 作品集展示优化视觉验收账本

## 验收基线

- 设计规格：`docs/superpowers/specs/2026-09-11-portfolio-showcase-optimization-design.md`
- 优化前参考：主工作区 `docs/audit/2026-09-11/04-interrogate-desktop.png`
- 最终生产截图：本目录 `portfolio-interrogate-hit-desktop.png` 与 `portfolio-interrogate-mobile.png`
- 原生视口：桌面 1440×900，移动 390×844
- 截图方法：Codex 内置浏览器 `tab.screenshot({ fullPage: false })`
- 视觉检查：优化前、最终桌面和最终移动截图在同一次 `view_image` 检查中直接比对。

## 保真与优化检查

| 检查点 | 优化前证据 | 最终渲染证据 | 处理结果 |
| --- | --- | --- | --- |
| 核心层级 | 审讯页主要是左侧资料与大面积聊天空白 | 资料、人物/对话、实时矛盾链形成三层结构 | 核心推理机制进入首屏 |
| 人物资产 | 嫌疑人仅用姓氏字块表示 | 复用现有 `ai-suspect.png`，以克制的暗色裁切进入人物栏 | 首页的电影感延续到内页 |
| 证据链 | 有效命中只在文字反馈与笔记里出现 | 证词、E02、命中矛盾在一条轨道中同时可见 | 评审者能在 30 秒内理解玩法 |
| 字体层级 | 对话与工具栏的视觉权重接近 | 嫌疑人回答使用档案宋体，玩家问题与系统标签保持 UI/等宽字体 | 人物声线与操作信息区分清楚 |
| 色彩系统 | 黑灰为主，状态分散 | 证据绿、风险红、真相金分别绑定选择、命中与封存 | 状态含文本与图标，不只依赖颜色 |
| 容器模型 | 中央区域过空，工作台偏后台工具感 | 保持开放画布和细边框，仅关键证据使用档案框 | 没有改成通用卡片或 Bento 面板 |
| 桌面适配 | 1440×900 对话区域宽但信息利用率低 | 三栏在 1440×900 无横向溢出，三段链路首屏完整可见 | 将证词压缩为一行摘要，释放矛盾结论空间 |
| 移动适配 | 资料抽屉可用，但核心进度不在对话主视图 | 390×844 顶部显示链路摘要，档案/证据/笔记仍由可访问抽屉打开 | 保留单主任务，无横向溢出 |
| 报告与复盘 | “关键证据”语义弱，矛盾列表关联不明显 | 改为“组建证据链”，复盘项同时显示矛盾与证据编号 | 不改变提交 payload 与固定评分逻辑 |

## 首屏文案核对

首页可见文案与原版本一致：品牌名、“用 8 次提问……”核心句和“生成案件”主按钮均未增删或改序。内页仅增加真实功能所需的“实时矛盾链”及其状态文本。

## 真实交互验证

- 本地访问令牌登录成功。
- 新案件不可用时，固定精修案兜底成功。
- E02 选择、提问提交、有效命中、证据发现、移动抽屉和三回合结案解锁成功。
- 结案报告三步结构化选择与确认提交成功。
- 结果页得到 S / 94，并正确展示玩家结论、固定真相、命中和遗漏矛盾。
- 最终生产预览控制台没有 error 或 warning。

## 有意保留的边界

- 用户明确选择不制作额外视觉 Mockup，因此本轮以现有电影化首页、优化前截图和书面设计规格作为视觉目标，没有生成新资产。
- 没有新增语音、视频或外部账户功能；它们会扩大权限、性能和演示稳定性风险。
- 后端案件生成、真相封存和固定评分契约保持不变。

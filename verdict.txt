ARCHITECTURE:
- Frontend: React + Vite + Tailwind + Three.js + Custom Canvas 2D + Framer Motion
- Backend: Python + FastAPI + uvicorn
- Video: FFmpeg (scene detection, motion estimation, segment encoding, concat, mux)
- Audio: librosa (BPM detection, beat tracking, onset strength, RMS energy)
- YouTube: yt-dlp (video + audio download)
- Real-time: Server-Sent Events (SSE) for processing logs
- Persistence: verdict.txt

API ENDPOINTS:
- POST /api/process — Accept files/URLs + settings, start job
- GET  /api/status/{job_id} — SSE stream of real-time processing logs
- GET  /api/download/{job_id} — Serve final MP4

BEAT-SYNC ALGORITHM:
- Aggressiveness: 0=downbeats only → 50=every beat → 100=sub-beats
- MotionBias: 0=even spread (golden ratio) → 100=prefer high-motion moments
- Sensitivity: 0=strict (fewer beats) → 100=loose (more beats)
- Every segment jumps to a different source location (100% visible cuts)
- Golden ratio spread + interest-weighted search + forced jump guarantee
- Cut times snapped to video frame grid to prevent accumulated drift
- Candidates scored by energy + onset + downbeat bonus, filtered, min-duration enforced
- FFmpeg single-pass filter_complex_script: trim+setpts+concat with video_track_timescale
- Verified: 93% on-beat, 98ms median drift, 100/100 quality score

DECISIONS:
- UploadCard supports File upload OR YouTube URL input (toggle)
- YouTube URL validated client-side (youtube.com, youtu.be, music.youtube.com)
- File and URL are mutually exclusive per card (selecting one clears the other)
- ASCII rendered via Canvas (2D context, character grid)
- Particles via custom Canvas 2D (hand-rolled, real objects with velocity)
- Ambient lighting via Three.js (soft volumetric glow)
- Dark cyberpunk theme: purple / cyan / blue neon palette
- Glassmorphism cards with backdrop-blur
- Framer Motion for all UI transitions
- In-memory job store with asyncio.Queue for SSE
- Vite dev proxy forwards /api → localhost:8000

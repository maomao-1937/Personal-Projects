# 连续创作交互审查 · 2026-09-13

本轮目标：减少「带着补充继续创作」的重复操作。保留现有摄影工作台、犬种选择、模型接入及原图切换，只调整提问、补充和执行衔接。

## 设计判断

产品核心仍是上传人像，表达造型意图，得到犬系分身。最重要的页面是创作工坊，主要用户是创作者以及需要观察 Agent 调度与模型差异的展示观众。本轮不重新定义全站视觉。

比较三种方向：保留底部提问并跳回输入框，会继续造成操作往返；新增独立聊天栏，会分散照片和创作入口；在原输入框上方就地提问，可以保持原有布局，使用现有按钮、文本框和字体层级。采用第三种，规则已同步 DESIGN.md 与 AGENTS.md。沿用 frontend-design 与浏览器审查方法，不新增 UI 库或开发侧 skill。

## Critique 与修正

| 具体问题 | 用户影响 | 修正与证据 |
| --- | --- | --- |
| 补充请求缺少此前用户要求和助手问题，仅附已有方案；尚无方案时尤其明显 | 简短回答可能被当成新任务，反复询问 | 请求携带当前照片最近六轮上下文；自动测试核对原要求、问题和本次回答，同时拦截同文本重复问题 |
| 问题在设置和主按钮下方，回答在上方 | 阅读问题后要寻找输入框，反复滚动 | 问题移动至原输入框上方，桌面与手机截图复查 |
| 必要澄清需要跳回输入框、输入、再找到提交按钮 | 选择本来很简单，却要多步完成 | 模型可返回 2–3 个可执行选项；手机单列、至少 44px 高，点选后直接进入生成；本地浏览器验证一次点击即生成 |
| 所有后续请求都用「带着补充继续创作」 | 用户无法区分回答问题、修改作品和重新生成 | 分别显示「发送并继续」「按这句调整」「再生成一张」，根据任务状态变化 |
| 开始下一轮时清空当前作品 | 等待和失败时失去可参考的上张结果 | 保留当前作品直至新图返回；浏览器在生成中、401 失败后均确认旧图存在 |
| 「方案通过后」容易被理解为需要用户批准 | 普通表情和嘴型也可能重复确认 | 运行时 skill 明确指向 propose_design 工具校验成功后直接绘图，普通细节自主决定；真实供应商的询问频率尚未验证 |
| 首轮改版的快捷回答说明重复调用上限，手机占两行 | 与底部说明重复，回答区变长 | 精修为「点选即继续创作，或在下方输入回答」，原有主操作区保留完整预算与数据发送说明 |
| 输入框辅助文字紧接犬种标题，层级间距不足 | 回答任务和犬种选择挤在一起 | 辅助文字下增加 12px 留白；手机隐藏桌面键盘提示，保留上下文说明 |

## 浏览器验证

独立本机测试入口 `http://127.0.0.1:8788/`，使用 `tests/fixture-server.ts` 的明确标记响应和示例图片；仅输入 fixture 测试字符串，不调用外部供应商。生产入口不引用该服务。

- 桌面实际 viewport 1440 × 900，手机 390 × 844；两者 DOM 检查均无横向溢出。最终原生浏览器截图分别为 [桌面](screenshots/continuation-desktop.jpg) 与 [手机](screenshots/continuation-mobile.jpg)。早期 CDP 截图出现固定元素位置失真，已用受支持的原生 viewport 与截图接口替换，不将失真截图作为证据。
- Enter 开始 → 就地问题、两个选项、空白回答不可提交；问题出现后输入框获得焦点。
- 手机点选「保留眼镜，直接生成」→ 显示真实执行状态 → 返回一个测试作品，无第二次提交。
- 补充文字 Shift+Enter → 文本包含换行且未启动；Enter → 启动，旧作品仍显示；完成后输入框清空、新版本出现。
- 已有作品、空白输入时按 Enter：不启动生成。按钮仍可明确点击「再生成一张」。
- 将隔离绘图模型改为 `qa-error` → 展示密钥/权限错误、草稿保留、旧图仍显示；恢复 `qa-success` 后原地提交成功。
- 重新使用示例人像 → 对话与本轮提问清除，标签恢复「这次，想怎么变？」。此前作品版本保留供查看，不携带旧对话到新照片。
- 精修后重新构建、刷新测试页，重新截图并验证文字回答 Enter 继续。
- 中文输入法组合状态已有 `isComposing` / 229 防护；自动化未覆盖真实操作系统输入法候选窗，不把代码检查称为原生输入法实测。

## Polish 与工程检查

沿用语义颜色、14px 提问正文、12px 辅助说明、现有 Radix/shadcn 控件和焦点样式；选项支持换行，手机单列，键盘提示只在桌面显示。保留手机唯一底部提交区、原有调用上限与停止等待。没有增加自动重绘、持久聊天或新的页面。

`npm test`：32/32 通过，新增必要澄清选项、多轮上下文/重复问题、输入长度和字段边界测试。`npm run build` 通过，包括 TypeScript、前端和服务端构建；原有主包大于 500 kB 的警告仍存在。

本轮完成本地实现、隔离响应交互验证及桌面/手机视觉复查。没有真实供应商密钥，尚未验证真实模型是否减少追问、最终造型质量或公开部署。重复问题拦截只覆盖忽略部分标点和空白后的相同文本，不代表语义相似问题全部可识别。

# 单一前后对照入口 · 2026-09-13

用户指出“切回自己”与滑块重复。保留缩略图按钮，默认完整展示结果；点击看完整原图，再点击看狗头效果。未修改上传、模型调用、记录或下载。

## Critique 与修正

1. 两个控件改变同一预览，用户需要先判断差别：移除滑块，只保留切换按钮。
2. 默认分界线切开犬头，难以第一眼看清完整造型：改为默认显示完整结果，左下仍可辨认原脸。
3. 大片透明 range 覆盖图片，整张图都暗含拖动操作：删除覆盖层，只有明确的按钮触发切换。
4. 滑块推到原图端点后仍显示结果标签：只显示当前画面的“原图 / 效果示例 / 生成结果”标签。
5. “返回对照”未明确下一次点击会看到什么，且缩略图始终是原图：按钮改为“切回自己 / 看狗头效果”，缩略图同步显示目标画面。
6. 带百分比的预览状态可能沿用到新作品：状态与当前版本 ID 绑定，新结果默认完整可见。

Polish：清除拖动说明及无用 CSS、图标；保留现有缩略图尺寸，补充 hover 与键盘 focus，忙碌时禁用切换。示例声明保留，未增加动画。

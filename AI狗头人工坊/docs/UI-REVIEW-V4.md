## 具体 Critique → 修改 → 复核

| 具体问题 | 影响 | 修改与复核 |
| --- | --- | --- |
| 首页同时有上传加号、上传主按钮和上传提示 | 不清楚应该点哪个 | 无照片时只保留一个有标签的上传按钮；示例入口为次级文字，桌面和手机已查看 |
| 桌面画布的 grid 默认最小尺寸把页面撑高约102px | 顶栏滚出视野、输入与作品无法稳定同屏 | grid 行使用 minmax(0,1fr)，画布 min-height:0；实测1440×900，documentHeight=900，无横溢出 |
| 手机建议和220px历史对话位于输入前 | 看完图无法立即找到修改入口 | 隐藏首轮装饰性建议，手机默认收起对话；首屏能看到版本、输入框和发送按钮，展开/收起均实际点击 |
| 修改框只有缩略图，未明确编辑版本 | 选择旧版本后容易改错对象 | 显示“正在修改版本 N”，选择版本1后原图切换与编辑上下文同步 |
| 会话可用与服务端已存状态混在一起 | 用户误以为刷新后仍然可用 | 设置显示“服务端已保存”或“会话可用，尚未持久保存”；假密钥保存后刷新，无需重填即可实际走本地模拟调用 |
| 首次上传会清掉先输入的想法 | 上传打断主任务 | 首次上传保留草稿；更换已有照片才创建新项目并清空旧语境 |
| 对比来源只在当前页面内存 | 刷新后可能退回手动提示词，实验任务变了 | 保存 compareSourceId 与 compareGroup；刷新后仍显示选中的狗头输入和两份已完成结果，导出核验指纹与提示词相同 |
| 对比图片切换写着“原始人像” | 连续编辑时实际输入是狗头作品，标签失真 | 改为“本次输入”，浏览器对比页已核对 |
| 历史版本缺少执行事件导出 | Agent 能力无法追溯，旧检查容易误用 | 每版本保存本轮事件与 Skill 身份、犬种与画面设置；恢复后记录仍在，手动重试清除旧检查/Agent事件 |
| 第一张手机结果文件实际390×244，与预期视口不符 | 不能充当手机验收证据 | 重新捕获并保存同一截图字节；sips验证为390×844，独立审查实际查看后通过 |

Polish 覆盖：统一黑色主操作和蓝色焦点/选择、系统字体、作品 contain、对齐和留白、单一原图切换、真实加载状态、错误就近提示、减少动态偏好、移动重排与对话折叠。复用现有 Radix 基础组件；没有增加虚假画布工具或样例计数。

## 浏览器与功能证据

使用内置真实浏览器，独立 QA 地址 http://127.0.0.1:8788/，假密钥和预制固定模型响应，只验证界面/接口流程，不调用外部模型。QA 凭证文件在独立 /tmp 目录，不修改真实站点配置。

- Desktop：1440×900；Mobile：390×844。截图尺寸由文件实测，未将缩放图当目标视口。
- 已执行：示例进入项目、Agent 首次创作及继续编辑、自己控制、选择旧版本、原图/结果切换、从作品进入对比、模型配置保存与刷新恢复、项目历史打开与新建。
- 失败恢复：将隔离模型改为 qa-error，提交后旧版本与草稿仍在；不重填已存密钥改回 qa-success，发送同一要求，新版本成功且错误/草稿清除。
- Enter 空输入未新增版本；Shift+Enter 只插入换行。手机展开/收起对话可用；弹窗 Escape 关闭。中文 IME 组合保护由实现与既有规则核对，没有真实手机输入法/软键盘测试。
- 下载：内置浏览器 download 事件两次超时，但系统 Downloads 中实际保存了两个本轮文件（版本1，3,141,817字节，1536×1024 PNG）；文件时间与点击对应。最终使用 Blob URL 下载。此处以实际文件为通过证据。
- 对比 JSON：两条 success，inputHash 完全相同，prompt 完全相同，sourceName 均为“选中的狗头作品”，无 apiKey。刷新后来源和结果均保留。
- Agent 作品 JSON：父版本存在、7条实际事件、仅工作流和造型 Skill，没有视觉检查记录，符合文字助手能力。QA 服务进程此前已缓存工作流1.0.0，导出如实记录所用版本；当前代码工作流1.1.0的加载身份与SHA由自动测试验证。

## 工程与部署边界

40/40 自动测试通过；TypeScript与前后端build通过。构建仍有主包约565KB的体积提示，未为本轮交付扩大到无关打包重构。

新增验证包括：选中版本图像实际作为输入；加密连接跨存储实例恢复；管理认证/跨站保护；公共配置排除密钥；客户端不能覆盖已存连接端点；生产管理与额度；项目快照白名单、父版本、Skill事件。生成上限由服务端执行。

服务端托管凭证使用AES-256-GCM，目录和文件权限限制，加密密钥同机；不是外部KMS。Docker上下文排除凭证目录，运行用户有私有数据目录；Docker镜像未在本环境构建。默认UTC日额度是单进程内存预留，重启重置，未实现持久账本/多实例预算。

真实供应商连通、看图/改图质量、真人照片效果、真实手机软键盘、公网部署与多实例运行均未验证；不据本地UI通过声称这些能力已验收。

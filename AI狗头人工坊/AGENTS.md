# 项目协作规则

## 项目事实与范围

- 开始任务时先读本文件、`DESIGN.md`、README、PRD、依赖配置、相关路由、组件、样式、设计文件及截图。缺失资料应明确记录，不得用猜测补成项目事实。
- 本目录在 2026-09-12 首次检查时为空；随后用户确认：上传人像生成狗头人，并接入不同图生图模型进行对比，作为可上线的面试展示项目。现有产品定义见 `PRD.md`。该记录是历史基线，后续以实际文件为准。
- 在产品定义缺失时，先完成不依赖产品假设的规范工作，并询问实际代码路径或最小产品说明。不得仅凭项目名生成业务功能、虚假指标或营销承诺。
- 优先保留已有有效结构、组件和交互。每项改动都应能解释具体改善了什么。
- UI 工作默认不改变业务规则、接口契约、权限、数据存储和计费。发现这些问题时单独说明，按用户授权范围处理。

## 设计先于实现

1. 梳理产品、用户、主任务、页面清单、核心页面和现有 UI 问题，注明证据。
2. 对比三个适合产品的视觉方向，从字体、密度、间距、导航、用色、组件构造和布局节奏说明取舍。已有明确设计参考时优先遵循。
3. 在 `DESIGN.md` 明确选定方向、设计 tokens、核心页面骨架及状态后再写前端。产品尚未确认的方案必须标为草案，不能当作已批准的业务规格。
4. 常规设计和可逆实现由代理自主推进；仅在缺失关键信息或超出授权时询问。不要把每一步都变成人工确认点。

## 实现规范

- 全产品遵循 `DESIGN.md`，使用语义化 tokens，避免页面各自硬编码颜色、间距和圆角。
- 优先复用项目已有 Button、Input、Dialog、Tabs、Tooltip、Dropdown 等基础组件；组件库选择须符合实际技术栈，不为设计任务擅自迁移框架。
- 信息层级依靠字体、留白、对齐与布局建立；分组不默认包裹 Card。
- 首屏说明用途、核心价值和下一步，同一任务区域仅有一个主要操作。
- 页面需覆盖真实需要的空状态、输入校验、加载、成功和错误。错误说明原因与恢复办法；AI 内容的示例、生成中与实际输出必须可区分。
- 使用真实产品内容；演示数据明确标注。不得把模拟生成、定时器或静态样例呈现为真实 AI 能力。
- 图标保持同一体系；按钮有可访问名称；输入有可见标签；键盘焦点清晰；弹窗处理焦点进入、返回及 Escape。
- 移动端重新安排内容顺序和操作位置，不只是缩小桌面布局。支持缩放、触摸和减少动态效果偏好。
- 检查设计工具是否适用即可，不必安装全套工具。不因工具不可用而编造检查结果。

## 浏览器验证与视觉审查

- 每完成一个主要页面，立即执行：实现 → 浏览器截图 → 审查 → 修正 → 重新截图。
- 至少检查桌面 1440 × 900 与移动端 390 × 844。记录实际 viewport，不得把缩放图或 CSS 推测当作相应尺寸的浏览器验证。
- 检查视觉重心、标题/正文字号、行高、容器宽度、边距、节奏、对齐、卡片和边框数量、圆角、阴影、主次操作、图标、中文换行、空状态、加载及移动端结构。
- 实际执行主任务、错误恢复、键盘操作和适用的移动交互；浏览器测试只使用受支持的工具接口。
- 必须做一次高级产品设计师视角的 UI Critique，记录至少五个具体问题、影响和修正，并用复查证据闭环。不要用“现代简洁”代替批评，不为凑数虚构缺陷。
- 最后执行 Polish Pass：字体、间距、对齐、圆角、边框、阴影、图标、Hover、Focus、Transition、空状态、加载及响应式。此轮不增加功能。
- 执行与变更相关的构建、检查和必要功能验证。不能以 build 通过代替真实浏览器审查。

## 交付标准

- 只有功能正常、桌面与移动端验证通过、设计系统一致、层级明确、视觉审查和精修完成，才可宣布 UI 完成。
- 交付说明包含：改动、改善原因、验证证据以及仍未验证的部分。区分设计草案、本地实现、浏览器验证、后端连通与上线状态。
- 本地完成不等于已部署；发布或外部写入遵循用户当前授权。

## 本项目的特定约束

- 图生图必须发送用户选择的人像作为图片输入，不得退化为纯文本生图。默认保留人类身体、姿势、服装和背景，只转换头部。
- 模型名称可显示，因为用户明确要求跨模型实验；底层协议细节集中到「模型接入」，不占用创作首屏。
- 密钥由用户在本地界面输入，只驻留当前页面内存；配置导出、本地持久化、日志、对比记录不得包含密钥或访问口令。刷新后需重新输入密钥。
- 模型对比锁定同一输入和提示词，记录真实状态、耗时、模型与参数；单次试验不能表述为模型能力排名。
- 示例作品必须持续标注，不计入模型实测结果；不将预制素材冒充用户图片的真实转换。
- 浏览器仅预览上传图片；点击生成或开始创作时才通过服务端发给所选供应商。Agent 理解发送原图，检查发送原图和结果，UI 说明须与实际数据流一致。
- 暂不添加账号、收费、社交作品社区、虚假评分或自动排行榜。

## V2 的长期规则

- 用户参考用于理解趣味性和任务表达，不能照搬颜色、版式、流程或装饰。每项修改须说明具体改善。
- 开发侧 UI skill 与产品运行时 skill 分开。产品指令位于 `agent-skills/`，必须实际加载并参与工具决策，禁止仅改名为 Agent。
- 展示真实工具状态、简短方案与观察证据；不得伪造思考，不从脸推断真实人格或身份。
- 绘图与理解调用上限由服务端执行。没有有效检查或用户未允许，不自动额外绘图；检查失败保留作品。
- 换照片清除旧方案和事件；版本与提示词绑定，手动生成不能沿用上一轮 Agent 检查作为本轮结论。
- 默认对照无需拖动也应能辨认原人脸和狗头结果；移动固定主操作不得遮住最终可滚达的内容，设置和弹窗须可键盘使用。
- 原图与结果对照只保留缩略图切换按钮，默认展示完整结果。不要再叠加滑块等重复入口；按钮说明下一步动作，图像标签说明当前显示内容。
- 当前已有 frontend-design、Impeccable 与 shadcn/Radix，新增工具应有明确必要性。
- 维护字体许可、图片精确提示词与来源。修改展示标题时同步自托管字体子集或明确回退。
- 犬种的表情、嘴型与舌头建议是可覆盖的创作默认值，不是固定生物特征或人格分类。参考图、手动提示词与 Agent 查询数据保持一致，用户明确表情要求优先。
- 理解模型能力按具体型号区分，不按厂商一概而论。文字模式不得发送图片、伪造图像观察、执行结果检查或自动二次绘图；这些边界由服务端执行，前端说明同步。
- 新增供应商同时核对官方模型 ID、完整接口、工具调用与图片输入能力、必要的推理字段回传和服务端域名规则。预设只代表文档适配，实际连通必须有真实调用证据。
- Agent 默认执行明确意图，不为普通造型细节索取方案批准。必要提问紧邻原输入框；可执行回答支持点选即继续，避免跳转输入框再重复确认。
- 补充请求须携带当前照片的最近对话和已有方案，换照片清除。保留失败草稿与已有作品；不把连续创作描述成跨会话记忆。服务端阻止已问过的相同文本问题。
- Enter 提交须处理中文输入法组合状态，Shift+Enter 换行；空澄清回答和连续创作的空 Enter 不提交。点击选项属于显式继续，调用上限仍由服务端执行，不随输入变化自动绘图。
- Agency Agents 等上游角色只作为方法参考；选择与当前任务相关的职责和验收规则，不整体复制人格、虚构成绩、固定框架命令或额外审批流程。保存来源与许可证，下载的参考文件不得自动进入运行时。
- 产品 Skill 由服务端白名单加载，记录实际版本及内容 SHA-256；检查 Skill 只有真正调用检查阶段才计入本轮记录。MCP、编排框架和独立模型角色仅在有具体执行需求时引入，不能用安装数量代替产品能力证据。

## 2026-09-14 已批准的项目式工作台
- 用户已明确批准复现 Lovart 核心图片创作界面和闭环；此要求覆盖先前仅作趣味参考的限制。品牌与核心任务不变，不承诺复现未实测的全部功能。
- 首次生成必须以人像为输入；“修改这张”必须以选中作品为输入，并保存原始人像和 parentId；“从原图再创作”回到人像输入。两类来源不得混淆。
- 用户已批准一次接入和作品历史。作品可保存在当前浏览器 IndexedDB，密钥不得进入浏览器持久存储。服务端托管连接必须受管理认证保护；原有会话连接依旧只保存会话密钥。
- 对比从作品冻结真实请求快照，不重新调用理解模型改写提示词。切换版本恢复该版本语境。
- 每个 Agent 版本保存本轮实际工具事件与 Skill 身份；历史恢复、版本选择、记录导出不得丢失来源。手动重试清除旧检查与 Agent 事件，避免冒认。
- 移动端历史对话默认收起，编辑输入紧接作品；失败提示不藏入折叠区域。主操作和当前编辑版本在首屏可发现。
- 托管凭证目录不得进入 Git、Docker 构建上下文或导出；容器运行用户需要可写的私有数据卷。单进程每日额度重启会重置，不能宣传为持久计费账本。

## 2026-09-14 模型 ID 与提示词生成器
- 新增绘图、理解、提示词模型时 ID 必须为空，由用户填写；选择供应商只可填接口提示，不自动选择型号。编辑现有配置保留其 ID。内部已知能力表只用于能力边界，不作为表单默认值。
- DeepSeek 提示词生成是独立的文字调用：无照片、不调用绘图、不替换现有助手。仅明确点击才调用一次；复制和应用不生成图片。返回应完整，失败/取消保留草稿与旧提示词，项目或选中版本变化使旧响应失效。
- 提示词连接复用管理认证和加密保存，不能将密钥放进项目、浏览器持久存储、模型输出、日志或导出；不以服务端保存代替真实账户连通证明。

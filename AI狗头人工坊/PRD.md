# 狗头人工坊 · 产品定义

## 用户与目标

产品作者希望上传一张人像，将人物变为狗头人，持续接入国内外图生图模型并比较实际效果。网站也用于向面试官、业务方和 AI 产品负责人展示可操作的产品与工程实践。

核心价值是用一个具体、可感知的图像编辑任务研究模型差异。不能用虚构指标、预制结果或团队级成果包装项目经历。

本文件按 V4 当前实现更新；下方带日期的 V2/2026-09-13 章节保留历史说明，冲突以 V4 为准。

## 核心任务

1. 维护者一次配置绘图模型、可选创作助手与默认模型，保存受保护的服务端连接。
2. 创作者上传人像，选择 Agent / 自己控制、目标犬种或一句要求，一次发送得到作品。
3. 选中版本直接描述修改，以该版本图像作为输入继续编辑；保留最初人像、父版本和历史，下载作品。
4. 从某次作品调用进入对比，以同一实际图片和完整提示词调用 2–3 个模型，比较并导出记录。

默认编辑意图：将人物头部替换为相应犬种的真实头部，保留人类身体、手、姿势、衣着、背景和光照。用户可补充提示词；结果质量由模型实际能力决定。

## 页面

- `/` 创作工坊：最重要页面，包含上传首页和项目画布/对话工作台，承载创作、版本选择、修改、下载；历史通过顶栏弹窗进入。
- `/compare` 模型对比：一致输入，多模型真实生成，独立成功/失败状态，不自动排名。
- `/models` 模型接入：受保护的托管连接保存、默认模型、会话密钥及无密钥配置导入导出。

## 当前边界

- 适配 OpenAI Images Edits、Google Gemini 原生图像响应、阿里云 DashScope 图像编辑、火山方舟 Seedream 图像生成接口。模型 ID 和端点可编辑，实际支持取决于供应商账户与接口兼容性。
- “国内外所有模型”作为可扩展方向，不作为首版已实现承诺；不同协议需独立 adapter，异步轮询接口需后续实现。
- API Key 可作为当前页面会话密钥，也可由维护者保存到服务器 AES-GCM 文件。生产管理须验证 STUDIO_ADMIN_TOKEN，前台不接收已存密钥。加密密钥同机保存，需保护并持久挂载目录；不声称外部 KMS 或账号体系。
- 图片、版本、草稿和当前项目上下文保存在浏览器 IndexedDB，刷新与历史打开可恢复；没有跨设备同步。服务器不落盘用户图片、不记录密钥。浏览器容量不足时提示下载。
- 初次访问可查看明确标注的预制 AI 示例；无密钥时不模拟真实生成。
- 不做账号、收费、作品社区、自动打分、模型排行榜。

## 关键验收

- 人像必须作为图像输入传给模型；上传文件验证格式、大小和可解码性。
- 参数修改不改变已生成记录的来源；对比每轮固定输入和提示词。
- 任何一个模型失败都能独立恢复，不隐藏已完成结果。
- 密钥不进入 localStorage、导出、日志或错误消息。
- 支持桌面 1440 × 900、移动端 390 × 844、键盘操作及真实错误反馈。
- 构建、适配器契约测试、浏览器交互和真实供应商测试分别报告。
- 上线前需要部署目标和可用 API 凭证；可部署代码与公开上线分开描述。

## V2 创作 Agent

用户于 2026-09-12 确认独立设计照片与创作意图优先的工作台，参考站仅提供趣味启发。创作为主、模型比较为辅，保留四协议适配与会话密钥管理。

- 24 犬种目录、别名搜索和自定义外观；摄影、绘画、3D 质感，默认仅头部编辑。
- 上传后表达想法；理解模型可查询犬种、提出澄清、制定结构化方案、调用绘图、对照原图检查，并在授权次数内修正。
- 三份实际加载的 skill 指导工作流、创作决策和检查，服务端执行参数校验、次数限制和输入边界。Skill 版本与内容指纹随真实执行阶段记录，文字模式不加载图像检查 Skill。
- 默认一次绘图，可允许一次自动修正；最多 10 次理解调用。无有效检查或未允许额外绘图时不自动重绘。
- 保留版本，支持原图对照、下载和执行记录导出。方案通过自然语言补充更新，尚无单独字段编辑器或跨会话记忆。
- 真实供应商质量验证和公开部署尚未完成，本地隔离测试不代表真实模型效果。

## 2026-09-13 连续创作交互

- 明确创作意图直接执行；仅目标人物不明或明确要求冲突时集中澄清，不索取通用的方案批准。
- 必要问题放在原输入框旁，可执行选项点击即继续，文字补充支持 Enter 发送、Shift+Enter 换行。手机保留一个底部发送入口。
- 当前照片最近六轮要求和提问随补充发送，保留已有方案；新照片清除上下文。新要求优先，失败保留草稿和已有作品。
- 空回答不提交，中文输入法选字不应触发请求；后台调用限制不变。暂不新增独立聊天页、持久聊天记录或自动无限重绘。

## 2026-09-13 接入与表现差异

- 24 个犬种均提供有区别的摄影参考与表情建议；嘴型、舌头状态进入手动提示词和 Agent 工具数据。用户明确要求覆盖默认造型，不能把表情解读为真实人格。
- 理解模型接入支持 OpenAI、千问、Gemini、DeepSeek、智谱、MiniMax、Kimi 及自定义兼容接口。按具体型号区分视觉与文字能力，不承诺整个厂商品牌都能看图。
- 文字模式依据文字制定方案并调用原有图生图接口；理解模型不收图，不产生图像检查结论，服务端最多允许一次绘图。视觉模式保留原有看图、检查与受限修正流程。
- 自定义接入包括模型 ID、完整端点、输入能力及会话密钥；新域名由维护者在服务端配置。不同鉴权、异步协议或非 Chat Completions 仍需独立适配。

## V4 当前验收边界（2026-09-14）

- 选中版本编辑发送该版本图像，保留原始人像和 parentId；不把每次修改退化为从头重画。
- 模型对比绑定实际调用的图片、提示词与参数记录，刷新后保持来源。
- 手机默认收起对话记录，作品后直接出现修改框；桌面画布与对话并排。
- 共享连接的调用受单进程额度约束（UTC 日最大绘图预留，默认100，重启重置）。生产站点仍需明确运维与费用控制；当前未公开部署。
- 40 项自动测试与隔离响应浏览器验收不是真实供应商质量证明。没有局部涂抹、无限画布、多账号云同步。

## 模型选择与提示词生成（2026-09-14补充）

- 绘图和理解模型 ID 始终由用户输入，新增或换供应商不填默认型号；已保存配置保留其 ID。
- 新增独立 DeepSeek 提示词生成器，入口位于创作输入区与设置页。连接可保存，不要求已有绘图/理解连接。
- 仅文字生成，一次显式提交调用一次；编辑或复制结果，应用填入当前创作框且不自动绘图。失败保留想法和旧结果，换项目或版本清理上下文。
- 单独记录和限制提示词调用，不宣称它看过照片，不展示内部思考。真实质量待有效 DeepSeek API 实测。

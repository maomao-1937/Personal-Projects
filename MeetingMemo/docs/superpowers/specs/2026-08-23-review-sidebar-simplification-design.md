# MeetingMemo 审核侧栏精简设计

> 日期：2026-08-23
>
> 状态：已按用户明确要求确认

## 目标

精简会议洞察侧栏底部，只保留与摘要审核直接相关的主操作，移除当前不需要的版本状态展示和外部分发界面。

## 变更

- 删除「当前版本 vN 已审批／待审批」整行。
- 删除「发送邮件」和「Slack」按钮。
- 删除「邮件与 Slack 均未配置」及其他分发状态提示。
- 保留「确认摘要／已审批此版本」主按钮，继续反映摘要审批状态。
- 审批成功提示改为「摘要已确认，现在可以导出。」

## 技术边界

- `MeetingWorkspace` 不再接收集成状态、分发回调和分发等待状态。
- `MeetingMemoApp` 不再为工作台加载集成状态或维护分发状态。
- API 客户端和后端集成接口保持不变，避免扩大本次纯界面精简的范围。

## 验证

- 组件测试断言版本元信息、邮件按钮、Slack 按钮和未配置提示均不存在。
- 组件测试继续确认审批按钮存在并可触发。
- 运行前端全部测试、ESLint、TypeScript 类型检查和生产构建。

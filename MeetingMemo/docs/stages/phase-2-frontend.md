## 阶段目标

基于已经核验的 FastAPI 后端，交付可运行、可编辑、可导出的 MeetingMemo 封闭 Beta 前端，并按 `DESIGN.md` 完成响应式三栏产品界面。

## 本阶段范围

- 邀请码兑换和会话恢复。
- 会议列表、会议创建、粘贴或上传转写。
- 摘要任务启动、轮询、失败重试。
- 会议转写、主题摘要、结论、决策、行动项和待确认问题。
- 来源片段定位。
- 摘要结构化编辑、版本冲突提示、审批。
- Markdown / TXT / JSON 导出。
- Slack / Email 配置状态与真实分发入口。
- 桌面、平板和移动端响应式布局。

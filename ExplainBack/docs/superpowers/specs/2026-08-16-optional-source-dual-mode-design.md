# ExplainBack 可选学习资料双模式设计

## 1. 目标

允许用户只填写学习主题即可开始训练，同时保留现有的资料约束能力。系统根据 `sourceText` 是否为空自动选择模式，不增加额外开关，不改变登录范围、训练状态机和日光水纹视觉。

## 2. 模式定义

### 2.1 资料约束模式

- 条件：`sourceText` 去除首尾空白后不少于 100 个字符。
- 知识地图：只从用户资料提取知识点。
- 判断与提示：只依据用户资料，不补充外部事实。
- `sourceContext`：必须是资料中的连续原文片段，并继续执行引用校验。

### 2.2 主题直练模式

- 条件：`sourceText` 去除首尾空白后为空。
- 知识地图：AI 根据学习主题和通用知识生成 1～10 个可训练知识点。
- 判断与提示：依据主流、稳定的通用知识；遇到争议、时效性强或无法可靠判断的内容时返回 `unclear`。
- `sourceContext`：保存 AI 为该知识点生成的简短“判断基准”，用于同一 Session 内保持判断一致；它不是用户资料，界面不得将其描述为用户引用。

不接受 1～99 个字符的资料。这样可避免用户误填一小段文字后，系统在两种模式之间产生模糊行为。

## 3. 用户界面

- 字段标题改为「学习资料（可选）」。
- 占位文案改为「可粘贴正文或 Markdown；留空则根据学习主题直接训练。」
- 帮助文案改为「留空：依据通用知识；填写：至少 100 字，并严格依据资料。」
- 资料为空时不显示字段错误，可直接提交。
- 资料为 1～99 个字符时显示「学习资料请留空，或至少输入 100 个字符」。
- 提交区说明改为「系统会根据主题或资料生成 1～10 个可训练知识点。」
- 现有布局、间距、按钮和响应式规格保持不变。

## 4. 数据与接口

- `POST /api/sessions` 继续接收 `sourceText`；允许为空字符串，也允许字段缺省并规范化为空字符串。
- 校验规则：`sourceText.length === 0 || sourceText.length >= 100`，最大 60,000 个字符。
- 模式由服务端根据已规范化的 `sourceText` 推导，不新增数据库列。
- SQLite 的 `source_text` 已允许空字符串，无需迁移。
- 创建 Session 的 `clientRequestId` 幂等规则保持不变；空资料也是请求内容的一部分。

## 5. AI 边界

新增统一的 `KnowledgeMode` 推导函数，供知识地图、回答判断和分级支持共同使用，避免三个调用点产生不同模式。

### 5.1 知识地图

- 资料约束模式使用现有提取提示词和 `sourceContainsContext` 校验。
- 主题直练模式使用独立提示词，要求输出知识点、简短描述和判断基准；不执行资料引用校验。
- 两种模式都执行相同的 Zod 结构校验、最多 2 次服务层尝试和 30 秒单次模型超时。

### 5.2 判断与支持

- 资料约束模式继续明确禁止使用外部知识。
- 主题直练模式允许使用通用知识，但禁止把有争议的观点伪装成唯一答案。
- 学习主题和资料都视为不可信数据，不得覆盖系统任务、输出 Schema 或安全规则。
- 确定性状态机继续负责 `learning / needs_review / mastered`，模型不能直接写状态。

## 6. Mock AI

- 空资料时，根据学习主题生成稳定的知识点和判断基准，保证免密体验可用。
- RAG 示例仍使用现有关键词判断，以便完整训练闭环保持可重复。
- Mock 行为只用于开发和验收，不伪装成真实知识来源。

## 7. 错误与恢复

- 主题直练模式生成失败时，仍先保存 Session，再进入现有失败与原地重试流程。
- 重试学习地图时继续从 Session 的空 `sourceText` 推导为主题直练模式。
- AI 配置缺失、超时、并发冲突和幂等返回沿用现有错误码和恢复逻辑。

## 8. 测试与验收

必须新增并通过以下测试：

1. 输入 Schema 接受缺省或空 `sourceText`，拒绝 1～99 个字符。
2. Session 表单只填写主题即可提交，并发送空字符串。
3. 资料约束模式仍执行原文引用校验。
4. 主题直练模式不执行原文引用校验，并能生成知识地图。
5. 主题直练模式的判断与支持使用通用知识提示词。
6. 空资料 Session 在失败后可使用同一 ID 重试。
7. Playwright 在桌面端和 360 px 移动端完成「只填主题 → 学习地图 → 训练」流程。
8. 原有有资料完整闭环、服务端失败恢复、并发 CAS 和幂等测试全部继续通过。

## 9. 完成标准

- 用户只填写至少 2 个字符的学习主题即可生成学习地图。
- 用户填写合格资料时，产品行为与当前版本一致。
- 页面明确告知两种模式的知识依据，不让用户误认为通用知识来自其资料。
- 无新增登录、搜索、联网取材、PDF 上传或数据库迁移。

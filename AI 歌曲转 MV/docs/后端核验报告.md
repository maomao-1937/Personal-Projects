## 3. 真实模型核验

### Storyboard

- 模型：本地 `.env` 配置的 OpenAI Compatible Storyboard 模型；
- 结果：通过；
- 证据：单次请求返回 6 个结构化 Cut，经 Schema 和 BeatPlan 业务校验后通过；
- 安全：未输出 Key，未将 Key 写入仓库。

### 百炼 Wan（当前默认）

- Provider：`dashscope_wan`；模型：`wanx2.1-t2v-turbo`；
- 官方约束：无声 MP4（H.264），支持 480P/720P，时长固定 5 秒且不允许修改；
- 适配策略：请求传具体 `size`，不传非法 `duration`；4—12 秒目标 Cut 由现有 FFmpeg 裁切或循环对齐；
- 离线契约：异步 Header、任务 ID、PENDING/RUNNING/SUCCEEDED/FAILED/CANCELED 状态、结果 URL、限流/鉴权/错误脱敏、结果下载安全限制已通过测试；
- 真实冒烟：按授权只创建 1 个任务并通过；结果为 832×480、H.264、无音频轨、5367 ms、4,283,674 bytes；
- 证据：脱敏任务 ID、状态和媒体元数据已保存到被 Git 忽略的 `.smoke/wan_result.json`，未保存 Key、Prompt、完整结果 URL 或完整任务 ID；
- 诊断说明：首次本地验收误用了“最终渲染文件”探测器，它强制要求音频轨，因此在远程任务已成功时报错。脚本已改用单 Cut 视频校验器，随后只查询原任务 ID 复验并通过，没有创建第二个任务。

### Seedance（历史诊断，现为兼容项）

- 冒烟输入：4 秒、16:9、480p；
- 尝试记录：共执行 4 次明确授权的创建尝试；前 2 次使用 `doubao-seedance-2-0-fast-260128`，第 3、4 次使用控制台模型详情页明确展示的 `doubao-seedance-2-0-260128`；
- 结果：前 3 次在创建阶段被拒绝且未保留安全错误码；第 4 次脱敏诊断明确返回 HTTP 404 与 `ModelNotOpen`，仍未返回任务 ID；
- 安全处理：第 4 次只输出本项目错误码、HTTP 状态与格式受限的上游错误码；未输出 Key、Prompt 或上游响应正文，随后立即停止；
- 控制台证据：标准模型 ID 为 `doubao-seedance-2-0-260128`；模型支持 Contents Generations，视频时长 4—15 秒、480p/720p/1080p/4k；账户中存在项目对应 API Key；
- 官方参数证据：`duration=4`、`ratio=16:9`、`resolution=480p`、`watermark=false` 均为 Seedance 2.0 支持值；
- 已排除假设：错误不能归因于 `fast` 模型名称，也不是时长、比例、分辨率或水印参数越界；
- 已确认根因：火山方舟返回 `ModelNotOpen`，当前账号尚未开通 `doubao-seedance-2-0-260128` 模型服务。浏览模型详情页和拥有 API Key 不等于完成模型开通。

# 分阶段前端开发文档

- 日期：2026-08-29
- 当前授权：阶段 F1，仅落地代表页 UI
- 当前停止点：Storyboard + Cut 工作区进入浏览器并完成视觉、响应式与本地交互验收

## 1. 总体策略

正式前端采用“代表页先行、真实闭环随后、全站最后扩展”的方式。首个代表页用于固化品牌、布局、状态语言和组件体系；在用户完成 UI 优化并明确确认前，不接入真实后端任务，也不扩展其他正式页面。

## 2. 技术基线

- Next.js App Router；
- TypeScript strict；
- Tailwind CSS 与语义化 CSS Variables；
- Lucide React 图标；
- Vitest + Testing Library；
- 后续真实接入统一使用 FastAPI `/api/v1`、Job 快照与 SSE；
- 前端不持有任何模型 Key。

## 3. 阶段划分

### F0：规格与视觉基线（已完成）

- 完成《前端技术适配声明》；
- 完成正式前端设计规格；
- 生成 Storyboard + Cut 代表页视觉概念；
- 确认混合明暗视觉方向。

### F1：代表页 UI（本轮授权）

目标：在浏览器中提供可操作的 Storyboard + Cut 工作区，供产品经理直接优化 UI。

包含：

- 将旧 Vite JavaScript 前端迁移为 Next.js + TypeScript strict；
- 建立页面设计 Token、字体、状态色和响应式断点；
- 实现全局顶栏、六步进度、音频波形和 Beat Marker；
- 实现 Scene 导航、Cut 卡片、Cut Inspector、底部 Preview 状态条；
- 用类型化本地 Fixture 展示成功、运行中、失败、排队和部分成功；
- 支持 Scene / Cut 选择、失败重试演示、字段编辑、保存状态和 Preview 过期提示；
- 提供桌面、平板、移动端布局；
- 完成 lint、typecheck、组件测试、production build 和浏览器截图对比。

不包含：

- FastAPI 真实请求；
- 邀请码登录；
- 真实音频上传、波形解析或播放；
- 真实 Qwen / Wan 模型任务；
- SSE、轮询和刷新恢复；
- Preview / Export 真实生成；
- 其他正式页面。

F1 完成后立即停止，等待 UI 优化与人工确认。

### F2：代表页真实后端闭环（未授权）

启动口令建议：`代表页 UI 已确认，接入真实后端`。

## 4. F1 验收标准

1. `npm run dev` 可打开代表页，不依赖后端或模型 Key。
2. 视觉结构与已确认概念一致：顶部项目条、六步流程、音频条、三栏工作区、底部状态条。
3. Cut 04 成功、Cut 05 运行中、Cut 06 失败、Cut 07 排队四种状态均清楚可辨，并且不只依靠颜色。
4. 点击 Scene / Cut 可切换选择；Inspector 跟随选择。
5. Cut 06 的重试演示只改变 Cut 06，不影响成功 Cut。
6. 修改 Cut 字段并保存后显示明确保存反馈；不伪装为服务端持久化。
7. 390、768、1280、1440 宽度无不可控横向溢出。
8. 所有可操作控件支持键盘焦点，触摸目标至少 44 × 44 px。
9. lint、typecheck、test、build 全部通过。
10. 浏览器截图与设计概念完成至少五项视觉对比记录。

## 5. 阶段停止规则

F1 达标后只汇报访问地址、已实现界面、验证证据和已知视觉差异，不主动开始 F2。产品经理完成 UI 优化并明确批准后再继续。

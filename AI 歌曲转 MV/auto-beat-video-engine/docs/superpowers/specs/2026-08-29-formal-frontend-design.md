# AI 歌曲转 MV 正式前端设计规格

- 日期：2026-08-29
- 状态：待书面确认
- 代表页面：Storyboard + Cut 生成工作区
- 视觉方向：C — 4i 信息架构与交互路径 + 本产品混合明暗品牌系统

## 1. 设计目标

正式前端服务于“一首歌从上传到下载 MV”的单一主链路。界面必须让非专业剪辑用户知道当前到了哪一步、AI 正在做什么、哪些 Cut 已成功、哪些 Cut 可以单独处理，以及当前 Preview / Export 是否仍对应最新时间线。

首个代表页不是静态样稿，而是后续全站的设计母版。它需要同时验证：

- 项目级导航和步骤进度；
- 音频、Beat 与当前播放位置的持续上下文；
- Storyboard 与 Cut 的层级和顺序；
- Cut 编辑、生成、失败、重试和重新生成；
- 部分成功时保留成功结果；
- Preview 的就绪、构建中和过期状态；
- 桌面端密集工作区与移动端降级方式。

## 2. 设计边界

### P0 纳入

- 邀请码登录、项目列表、新建项目；
- 音频上传与 librosa 分析结果；
- Plot + Storyboard 生成、修改、确认；
- 最多 12 个 Cut 的独立生成，界面最多同时展示 2 个运行中任务；
- 单 Cut 失败重试、重新生成；
- Beat 驱动的 Timeline 只读展示；
- Preview 构建、过期和重建；
- 16:9、9:16 两个独立 Export 任务及 MP4 下载；
- 刷新、断网、SSE 中断后的状态恢复。

### P0 不纳入

- 专业多轨剪辑器；
- Characters / Environments 完整资产系统；
- 多候选图片工作流；
- 复杂 Lipsync Timeline；
- 社区、会员积分、支付、多人协作。

## 3. 竞品结构的采用边界

从现有 4i 证据中采用以下已观察结构：

- 项目工作区顶部保留音频播放和波形上下文；
- 用清晰步骤表示 Setup / Build / Export 的阶段关系；
- Scene / Segment 导航与 Cut 卡片组合；
- Cut 与 Video 生成结果分层表达；
- Preview 使用大画面播放器；
- Export 独立成页并展示统计、状态和下载入口。

不复制以下内容：

- 4i 品牌、Logo、原文案、积分和价格表达；
- 未经证据验证的登录、付款、删除细节；
- Timeline Export 复用旧 Director 内容的异常行为；
- 超出本项目 P0 的人物、环境、多候选图片和 Lipsync 能力。

## 4. 产品信息架构

### 全局页面

1. `/invite`：邀请码登录。
2. `/projects`：项目列表、空状态、新建项目入口。
3. `/projects/new`：命名项目、上传音频。
4. `/projects/[projectId]/analysis`：音频分析结果和创意简述。
5. `/projects/[projectId]/storyboard`：Plot、Storyboard、Cut 编辑与生成。
6. `/projects/[projectId]/preview`：当前时间线 Preview。
7. `/projects/[projectId]/export`：16:9 与 9:16 独立导出。

### 项目内步骤

统一显示以下 6 步：

1. 音频
2. 分析
3. 故事
4. 镜头
5. 预览
6. 导出

步骤状态只由后端现有资源和任务状态推导，不在前端单独维护“已完成”布尔值。

## 5. 代表页：Storyboard + Cut 工作区

### 桌面端结构

#### A. 全局顶栏

- 产品标识与“返回项目”；
- 项目名称；
- 保存状态；
- 网络连接状态；
- 当前用户菜单。

#### B. 项目进度与音频条

- 六步步骤条；
- 播放 / 暂停、当前时间 / 总时长；
- 音频波形；
- Beat Marker；
- 点击波形定位播放位置；
- 当前选中 Cut 的时间范围高亮。

波形不是完整编辑器，不支持拖拽改变 Cut 长度。P0 仅用于导航和解释自动卡点结果。

#### C. 左侧 Scene 导航

- 显示 Scene 顺序、标题、时间范围、Cut 数量；
- 显示 Scene 聚合状态：未确认、待生成、生成中、部分成功、完成、失败；
- 点击切换中间内容；
- 不提供 Characters / Environments 二级入口。

#### D. 中间 Cut 画布

- 顶部显示当前 Scene 标题、时间范围、Plot 摘要；
- Cut 按时间顺序排列；
- 卡片包括序号、时间范围、提示词摘要、预览图或视频、状态和主要操作；
- 成功 Cut 始终保留；
- “生成全部”只为尚未成功且当前允许生成的 Cut 建任务；
- 运行中 Cut 可展示进度或阶段文本；
- 失败 Cut 就地显示错误摘要和“重试”；
- 成功 Cut 提供“播放”“编辑”“重新生成”。

#### E. 右侧 Cut Inspector

选中 Cut 后显示：

- 标题或镜头目的；
- 视频提示词；
- 景别；
- 镜头运动；
- 时间范围与时长（P0 只读，由时间线和 Beat 决定）；
- 当前资产版本、生成状态、失败原因；
- 保存修改、重试、重新生成。

若后端 Storyboard PATCH 的字段范围小于上述设计，前端首版只开放真实可写字段，其他信息按只读展示，不制造假保存。

#### F. 底部任务与 Preview 条

- 汇总 `成功数 / 总数`、运行中和失败数；
- 当前 Preview 状态：未生成、构建中、就绪、过期、失败；
- “构建 Preview”或“重新构建 Preview”；
- Preview 就绪后提供进入 Preview 页的主按钮。

### 平板与移动端

- 768–1023 px：左侧 Scene 收为抽屉，Inspector 保留窄栏或抽屉；
- 小于 768 px：工作区改为单列，顶部保留紧凑音频条，Scene 和 Inspector 均为底部抽屉；
- Cut 卡片一次只展示一个主操作，其他操作进入菜单；
- 所有触摸目标至少 44 × 44 px；
- 移动端不尝试复刻桌面时间线密度。

## 6. 视觉系统

### 方向

采用混合明暗工作区：

- 应用外壳与视频预览区使用深石墨色，承载播放、生成和时间线；
- Plot、Storyboard 表单与 Cut Inspector 使用浅暖灰面板，提升长文本可读性；
- 主要动作使用紫蓝色，不使用 4i 的棕色品牌色；
- 状态色独立：成功绿、运行蓝、等待琥珀、失败红、过期灰紫；
- 避免大面积玻璃拟态、霓虹描边和无意义 3D 背景。

### 设计 Token 初稿

- `--bg-shell`: `#11131A`
- `--bg-stage`: `#181B24`
- `--surface-warm`: `#F4F1EA`
- `--surface-card`: `#FFFEFB`
- `--text-on-dark`: `#F7F8FB`
- `--text-primary`: `#1B1D24`
- `--text-muted`: `#6E7280`
- `--brand`: `#6D5DFB`
- `--brand-hover`: `#5847ED`
- `--success`: `#218A57`
- `--warning`: `#C17A16`
- `--danger`: `#C74747`
- `--running`: `#3478F6`
- 圆角：8 / 12 / 16 px；
- 阴影：只用于层级浮起和抽屉，不做持续发光；
- 字体：优先系统中文字体栈，数字和时间使用等宽字体子集。

最终 Token 在代表页视觉验收后固化为设计系统文件；未经确认不覆盖已有设计资产。

## 7. 状态与交互规范

### 后端任务映射

| 后端状态 | 界面状态 | 用户可执行动作 |
|---|---|---|
| `accepted` / `queued` | 排队中 | 查看队列，不重复提交 |
| `running` | 生成中 | 查看阶段与进度 |
| `failed_retryable` | 可重试失败 | 单 Cut 重试 |
| `unknown_provider_state` | 状态确认中 | 自动查询快照，不立即重复生成 |
| `succeeded` | 已完成 | 播放、编辑后重新生成 |
| `failed_terminal` | 生成失败 | 修改提示词后重新生成 |
| `timed_out` | 已超时 | 查看说明，按规则重试 |
| `cancelled` | 已取消 | 重新发起 |

### SSE 与恢复

- 创建任务后立即保存 `job_id`；
- 首次载入先拉取 Job 快照，再连接 SSE；
- 记录最后事件序号，重连传递 `after` 或 `Last-Event-ID`；
- SSE 中断只显示“连接中断，正在恢复”，不把任务改成失败；
- 重连失败时降级轮询；
- 页面刷新后通过 Project、Storyboard、Cut status、Timeline 和 Job 快照恢复；
- 所有昂贵 POST 使用唯一 `Idempotency-Key`，按钮在请求确认前不可重复点击。

### 部分成功

- Scene 和项目允许显示“部分成功”；
- 成功 Cut 的视频和资产版本保持不变；
- 失败 Cut 单独重试；
- “重试失败项”不重跑成功 Cut；
- Preview 可以仅在后端允许的完整度下生成，界面明确标记其完整度，不伪装为完整 MV。

### Preview 与 Export 版本

- Preview 始终绑定 `timeline_version_id`；
- Cut 资产、顺序、比例或相关内容变化后，旧 Preview / Export 显示“已过期”；
- 旧文件仍可按后端策略查看，但不能显示为“当前版本已导出”；
- 16:9 和 9:16 分别创建任务、分别展示状态和下载按钮；
- `export_url` 或 Artifact 存在不等于当前时间线已导出。

## 8. API 与前端数据边界

前端只消费真实 `/api/v1` 接口：

- 邀请码认证与 Bearer Session；
- Project 新建、列表、详情；
- 音频上传与分析任务；
- Storyboard 生成、读取、修订、确认；
- Cut 聚合状态、批量生成、单项生成 / 重试 / 重新生成；
- 当前 Timeline；
- Preview 与 Export；
- Job 快照、历史事件和 SSE；
- Artifact 下载。

后端是资源状态、任务状态和版本状态的唯一事实来源。前端不持久化伪任务、不推测任务成功、不使用旧 URL 覆盖当前版本状态。

## 9. 前端组件边界

- `AppShell`：全局导航和用户上下文；
- `ProjectProgress`：项目步骤推导；
- `AudioContextBar`：播放、波形、Beat、高亮范围；
- `SceneNavigator`：Scene 列表与聚合状态；
- `CutGrid` / `CutCard`：镜头内容和状态；
- `CutInspector`：真实字段编辑；
- `JobStatusBadge` / `JobProgress`：统一任务反馈；
- `PreviewStatusBar`：Preview 版本与动作；
- `ApiClient`：认证、错误标准化、幂等键；
- `JobStream`：SSE、游标、重连和轮询降级。

页面专属组件与路由共置；跨页面稳定复用后再提升到公共目录。

## 10. 代表页验收标准

1. 1280 和 1440 宽度下，Scene、Cut、Inspector 三层关系无需说明即可识别。
2. 390 和 768 宽度下无横向溢出，核心生成与重试动作可完成。
3. 可通过键盘进入所有按钮、表单、Cut 卡片和抽屉，焦点清晰。
4. 空、加载、排队、运行、成功、部分成功、可重试失败、终止失败、断网、恢复、过期状态均有明确界面。
5. 单 Cut 重试不会改变成功 Cut 的可见结果。
6. 单 Cut 重新生成后，当前 Preview 明确变为过期并引导重建。
7. 刷新页面后从后端恢复真实状态，不出现任务倒退或重复提交。
8. 页面不包含真实模型 Key、Provider Key、内部 Base URL 或成本敏感信息。
9. 与 4i 相同的是信息架构和操作逻辑，不出现其品牌素材和原文案。

## 11. 后续页面扩展顺序

代表页确认后按以下顺序扩展：

1. 邀请码登录 + 项目列表；
2. 新建项目 + 上传音频；
3. 音频分析 + Plot；
4. Storyboard + Cut 真实闭环；
5. Preview；
6. Export；
7. 响应式、可访问性和异常恢复收口。

## 12. 当前待确认

本规格没有新增会显著改变范围、成本或安全的产品决策。代表页采用已确认的 C 方向；实现阶段仅需确认视觉结果是否作为全站母版。

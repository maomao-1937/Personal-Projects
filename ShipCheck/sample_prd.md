# Sample PRD — 极简登录页

> 用于 ShipCheck 真实混元冒烟测试。配合 https://example.com(或任意简单公开站)跑验收;单独跑审查。

## 1. 产品目标
做一个极简登录页,让用户用邮箱 + 密码登录,登录成功后跳转到 dashboard 页面。成功指标:登录 P95 时延 < 2s,登录后 95% 用户到达 dashboard。

## 2. 用户与主链路
- 主用户:已注册用户
- 主链路:打开登录页 → 输入邮箱和密码 → 点击登录 → 跳转 dashboard

## 3. 功能
- F1 登录页:页面包含邮箱输入框、密码输入框、登录按钮
- F2 登录校验:点击登录后,正确凭证跳转 dashboard,错误凭证提示"邮箱或密码错误"
- F3 dashboard:登录成功后展示用户名

## 4. 边界
- 不做注册、找回密码、第三方登录
- 不做记住我

## 5. 失败路径
- 邮箱为空时登录按钮禁用
- 密码错误 3 次锁定 15 分钟
- 网络超时(>5s)提示"网络异常,请重试"
